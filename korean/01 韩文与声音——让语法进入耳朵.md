# 韩文与声音——让语法进入耳朵

目标：把看到的语法形式和听到的声音连起来。若已能读韩文，直接做自测；否则给这一关 2—3 次短练习，后续继续巩固。

## 音节块怎么读

韩文音节通常是“声母＋元音＋可选收音”：`한 = ㅎ＋ㅏ＋ㄴ`。元音前的 `ㅇ` 不发声，如 `아`；音节底部的 `ㅇ` 是鼻音，如 `강`。不能把每个字母都读成一个独立音节。

先认识基本元音 `ㅏ ㅓ ㅗ ㅜ ㅡ ㅣ ㅐ ㅔ`，再扩展 `ㅑ ㅕ ㅛ ㅠ` 与 `ㅘ ㅝ ㅚ ㅟ ㅢ` 等。`ㅓ` 与 `ㅗ`、`ㅡ` 与 `ㅜ` 不要用同一个日语元音代替；现代口语中的 `ㅐ/ㅔ` 常接近，也不用因此卡住。

辅音先按组听：`ㄱ/ㅋ/ㄲ`、`ㄷ/ㅌ/ㄸ`、`ㅂ/ㅍ/ㅃ`、`ㅈ/ㅊ/ㅉ`，另有 `ㅅ/ㅆ`。同时认识 `ㄴ、ㅁ、ㄹ、ㅇ、ㅎ`。平音、送气音、紧音的区别不能简化为日语“清音／浊音”；词中听起来像浊音只是其中一种现象。跟官方词典音频模仿，不长期用假名或汉字注音。

## 收音既影响发音，也影响语法

名词末尾有无 받침（收音），会决定很多助词的形态：`책은`／`영화는`，`책을`／`영화를`。词干有没有收音，也影响 `먹으면`／`가면`。

常见收音在音节末尾归并为七类声音：`ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅇ`。末尾 `ㄱ ㄷ ㅂ` 不要补一个日语式元音：`책` 不是“チェク”两个完整音节。

## 先识别五种声音变化

下表方括号是韩文读音提示，不是原拼写；先按具体词记，不把它当作所有环境通用的替换表。

| 拼写 | 读音提示 | 要识别的现象 |
|---|---|---|
| 한국어 | [한구거] | 收音接元音，发生连音 |
| 먹어요 | [머거요] | 助词／词尾边界在声音里不一定清楚 |
| 국물 | [궁물] | 鼻音化 |
| 같이 | [가치] | 腭化 |
| 좋다 | [조타] | ㅎ 参与送气化 |
| 학교 | [학꾜] | 紧音化 |
| 합니다 | [함니다] | ㅂ 在鼻音前变化 |

日语汉字词迁移有时能提示词义，但韩语的收音和音变会遮住这个线索。例如 `한국어` 听到的表面声音不等于逐字读“한／국／어”。

## 15 分钟操作

1. 在 [[00 韩语语法入门地图——日语迁移路线#材料与来源|官方材料入口]] 找字母课程或词典音频。
2. 选择 `한국어、학교、영화、친구、먹다`，先看拼写再听；每词模仿两次。
3. 把 `먹다 → 먹어요` 放一起听，注意词干在不同环境下的声音。
4. 最后关掉文字听一遍，写“我认出了哪个词／哪段词尾”。不要求一次能准确默写。

## 自测

1. `한、아、강` 的 `ㅇ` 或收音分别在哪里？
2. 为什么 `책` 后用 `은`，而 `영화` 后用 `는`？
3. `먹어요` 实际读音里，还能听到清晰分开的 `먹／어요` 吗？

<details><summary>参考答案</summary>

1. 한 的收音是 ㄴ；아 的初声 ㅇ 不发声；강 的收音 ㅇ 发鼻音。
2. 책 有收音，영화 无收音；这是助词形态选择，不是话题意义不同。
3. 通常会连音成 [머거요]，语法边界要结合拼写与已知结构恢复。

</details>

过关：能解释音节块和收音，并借音频区分至少三组辅音。接 [[02 句子骨架——助词块与句尾]]；发音不必等到完美才学语法。
