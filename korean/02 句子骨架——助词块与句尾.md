# 句子骨架——助词块与句尾

目标：即使遇到生词，也能先圈出谓语和名词块。

## 从日语迁移的主框架

日语：私は／家で／映画を／見ます。  
韩语：저는／집에서／영화를／봐요。

`저` 我，`집` 家，`영화` 电影，`보다` 看。基本陈述句常把谓语放在最后，助词标记名词与谓语的关系；语序可以因话题与强调改变。口语也可能把补充成分放到句尾之后。

先抓四类块：

| 块 | 韩语 | 日语功能近似 |
|---|---|---|
| 话题 | 저는 | 私は |
| 主语 | 친구가 | 友達が |
| 宾语 | 영화를 | 映画を |
| 情境 | 집에서／오늘 | 家で／今日 |

话题与主语不一定是同一个成分；“每句都有主谓宾”也不是必要条件。`좋아요` 就可能是完整的“好／喜欢／可以”，具体所指看语境。

## 四类常见谓语

| 类型 | 韩语句子 | 日语／中文 |
|---|---|---|
| 动作 | 친구가 와요. | 友達が来ます。朋友来。 |
| 性质／状态 | 날씨가 좋아요. | 天気がいいです。天气好。 |
| 名词判断 | 저는 학생이에요. | 私は学生です。我是学生。 |
| 存在／拥有 | 시간이 있어요. | 時間があります。有时间。 |

韩语形容词也会活用；`좋다 → 좋아요`。不要根据日语词类替它自动加一个“です”。名词判断则用 `이다` 的形式，见 [[04 谓语活用——词干与词尾积木]]。

## 阅读拆句五步

1. 找最外层的主句谓语，不把修饰从句中的谓语当成全句结尾。
2. 在名词后找助词，划分话题、主语、宾语、地点。
3. 检查谓语中的否定、过去、敬语、推测。
4. 看中间谓语是连接下一句，还是修饰后面的名词。
5. 再补生词与省略成分；对不明确的施事保留问号。

### 拆一个略长的句子

**저는 오늘 친구하고 카페에서 한국어를 공부해요.**

```text
저＋는 / 오늘 / 친구＋하고 / 카페＋에서 / 한국어＋를 / 공부하＋여요 → 공부해요
我－话题 / 今天 / 与朋友 / 咖啡馆－动作地点 / 韩语－宾语 / 学习－礼貌结尾
```

日语：私は今日、友達とカフェで韓国語を勉強します。`하고` 接在名词后是“和／与”；接在 `하다` 的词干后又可能是动词连接形式，要看前项。

## 听力时怎么用

听到 `카페에서`，暂存“地点”；听到 `한국어를`，预期后面有关于韩语的动作；听到 `공부해요`，确认学习。暂时没认出名词，也可以先记“X－宾语／Y－动作”。

## 自测

1. 切块：`친구는 집에서 음악을 들어요.`（음악 音乐，듣다 听）
2. `시간이 없어요.` 没有宾语，是否仍是完整句子？

<details><summary>参考答案</summary>

1. 친구는／집에서／음악을／들어요：朋友－话题／在家／音乐－宾语／听。日语：友達は家で音楽を聴きます。
2. 是。主语 시간이＋不存在的谓语 없어요，表示没有时间。

</details>
