# 引用推测与意图——句子套句子

目标：听懂说话人是在陈述、转述、猜测，还是承诺自己的行动。

## 日语的「と」对应一组韩语引用词尾

直接引用可用 `"…"라고 말하다`；间接引用会按前面句子的类型变化。

| 被引用内容 | 常见形式 | 示例与日语近似 |
|---|---|---|
| 动词当前陈述 | -ㄴ/는다고 | 간다고 했어요. 行くと言いました |
| 形容词当前陈述 | -다고 | 좋다고 했어요. いいと言いました |
| 名词判断 | -(이)라고 | 학생이라고 했어요. 学生だと言いました |
| 过去陈述 | -았/었다고 | 갔다고 했어요. 行ったと言いました |
| 疑问 | -냐고 等 | 어디 가냐고 물었어요. どこへ行くのか尋ねました |
| 命令 | -(으)라고 | 오라고 했어요. 来るように言いました |
| 提议 | -자고 | 같이 가자고 했어요. 一緒に行こうと言いました |

动词当前：无收音 `가다 → 간다고`，有收音 `먹다 → 먹는다고`，ㄹ 收音脱落，如 `살다 → 산다고`。这不同于 `가는 사람` 的名词修饰。疑问引用的细分形式第二轮再补，首轮先认引用框架。

**친구가 [내일 온다고] 했어요.**  
朋友说他明天来。／友達が明日来ると言いました。

主句谓语是“说了”，引用里面的动作是“来”。引用小句的主语常省略，不一定永远与主句主语相同；需要上下文。

`친구가 가라고 했어요`＝朋友叫某人去。不能因为 가- 后出现 라고 就译成朋友说自己要去。

## 推测与意图分开看

| 形式 | 常见理解 | 日语近似与限制 |
|---|---|---|
| -(으)ㄹ 것 같다 | 好像会……／可能…… | ～そうだ／～と思う，依语境 |
| -는 것 같다 | 好像在……／好像…… | ～ようだ |
| -겠- | 意志、推测、委婉等 | ～겠＝将来 是过度简化 |
| -(으)ㄹ게요 | 说话人承诺／决定行动，顾及对方 | ～しますね |
| -(으)ㄹ래요 | 自己的意愿；问句可问对方意愿 | ～したい／～する？ |

`맛있겠어요` 看起来／想必好吃，不是“将来好吃”。`제가 할게요` 我来做；`뭐 먹을래요?` 你想吃什么？`갈 거예요` 更像计划／预期，不能在任何场景直接替换 할게요 的回应功能。

官方核查：[-겠- 条目](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=90137)列有未来／推测、意志、可能或能力、委婉等用法。

## 口语转述缩约先认三组

`간다고 해요 → 간대요`，说要去／听说要去。  
`학생이라고 해요 → 학생이래요`，说是学生／听说是学生。  
`가자고 해요 → 가재요`，提议一起去。

这些是结构识别线索，具体是谁说的、消息是否可靠由语境判断。不要把 `-대요` 一律当成说话人的亲眼确认。

## 自测

1. 区分 `간다고 했어요`／`가라고 했어요`／`가자고 했어요`。
2. `맛있겠어요` 是确定事实吗？
3. `제가 할게요` 里谁承担行动？

<details><summary>参考答案</summary>

1. 说要去／叫某人去／提议一起去；陈述引用、命令引用、提议引用。
2. 不是，常是根据外观或情境作出推测。
3. 제가 指说话人“我”，할게요 常承诺自己来做。

</details>
