# 礼貌敬语与句型——听出对谁说

目标：不要把“礼貌程度”误听成新的动作，也不要漏掉请求与提议。

## 分开两条轴

1. 对听者怎么说：普通礼貌 `-아요/어요`，较正式 `-(스)ㅂ니다`，亲近口语 `-아/어`。
2. 对所谈论的主语是否尊敬：词干后插入 `-(으)시-`，也可能用专门词汇。

| 例子 | 分析 | 日语近似 |
|---|---|---|
| 친구가 와요. | 对听者礼貌，没有主语尊敬标记 | 友達が来ます。 |
| 선생님이 오세요. | 오＋시＋어요 → 오세요 | 先生がいらっしゃいます。 |
| 선생님이 오셔. | 尊敬主语，向听者用亲近口语 | 先生がいらっしゃるよ。 |

`-세요` 在不同语境中也可能是请求：`오세요` 请来。不是一听到 세요 就一定是命令。

## 同一个动作的三种面貌

| 词典形 | 日常礼貌 | 正式礼貌 | 亲近口语 |
|---|---|---|---|
| 가다 | 가요 | 갑니다 | 가 |
| 먹다 | 먹어요 | 먹습니다 | 먹어 |
| 하다 | 해요 | 합니다 | 해 |

正式陈述结尾通常无收音用 `-ㅂ니다`，有收音用 `-습니다`；ㄹ 收音在这里脱落：`살다 → 삽니다`。正式疑问 `-ㅂ니까/습니까`：`갑니까?、먹습니까?`。

先学这三组即可，不需要把所有传统语体一次背完。对白里形式变化也可能反映身份、距离或情绪。

## 陈述、疑问、请求、提议

| 例子 | 功能 | 日语近似 |
|---|---|---|
| 지금 가요.／지금 가요? | 同形式可陈述或提问，靠语调与语境 | 今行きます／今行きますか |
| 어디 가요? | 哪里去；어디 是疑问词 | どこに行きますか |
| 같이 갈까요? | 要不要一起去／一起去怎么样 | 一緒に行きましょうか |
| 같이 가요. | 某些语境下是邀请 | 一緒に行きましょう |
| 앉으세요. | 请坐 | 座ってください |
| 먹지 마세요. | 请不要吃 | 食べないでください |
| 같이 가자. | 亲近口语提议 | 一緒に行こう |

`-(으)ㄹ까요` 还可询问猜测，如“会不会下雨”；不能只背成“ましょうか”。

## 敬语词先被动认识

`있다 → 계시다`（人存在的尊敬），`먹다 → 드시다`（吃的尊敬），`자다 → 주무시다`（睡的尊敬）。`주다 → 드리다` 常表达给尊敬的接受方，是另一种尊敬关系。不要简单把所有敬语都理解为“动词主语更尊贵”。

## 自测

1. `선생님이 오셨어요` 的 시、었、어요 各做什么？
2. `먹어요?` 是否一定省略了疑问词？
3. 解释 `지금 가지 마세요`。

<details><summary>参考答案</summary>

1. 主语尊敬／过去／对听者的日常礼貌；시＋었 缩约为 셨。
2. 不一定，可以是“吃吗／正在吃吗”等是非问。
3. 现在请不要去，가-지 마-세요 是禁止结构。
