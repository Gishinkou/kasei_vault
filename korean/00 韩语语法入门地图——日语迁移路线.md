# 韩语语法入门地图——日语迁移路线

## 这套笔记要解决什么

先能看清句子的“架子”：谁／什么是话题，谁在做什么，动作发生在哪里，从句修饰谁，句尾在否定、推测、请求还是转述。学习重点是**阅读拆句与影音听辨**，暂不追求完整的主动表达或考试覆盖。

### 我的起点与待验证假设

- 日语水平不错，可以借用助词、谓语后置、修饰语在名词前、语境省略等已有直觉。
- 能凭发音迁移一些韩语汉字词和英语外来语；具体能迁移多少，需要用真实音频验证。
- 工作假设：先掌握高频结构，再借熟词增加可理解输入。它能降低理解成本，但不能保证直接听懂自然语速。

## 一张骨架图

```text
[名词＋助词] [名词＋助词] … [谓语词干＋中间词尾＋结尾]
     │              │                   │
   话题／主语      对象／地点         动作、状态、判断
                                         │
                  ┌──────────────────────┼─────────────────────┐
               结束句子                连接下一小句          修饰名词
            먹어요 吃／吃吗         먹고 吃了然后…          먹는 사람 吃的人
```

分析文字可以先找最右边的主句谓语，再向左找它的对象和条件。听力则不能倒放思维：按顺序暂存名词块，遇到连接词尾或修饰词尾时识别边界，等句尾确认立场。

例如：**어제 친구가 추천한 영화를 집에서 봤어요.**

```text
[[어제 친구가 추천한] 영화]를 / 집에서 / 봤어요
 [[昨天朋友推荐的] 电影]－宾语 / 在家－动作地点 / 看了－礼貌句尾
```

日语：昨日友達が勧めた映画を家で見ました。`어제` 在这里按“昨天推荐”解析；在其他上下文中也可能修饰主句的“看”，时间范围要结合语境。

## 怎么开始

今天先读 01、02，完成各自自测。随后按 [[14 四周学习计划——从拆句到影音输入]] 推进，在 [[15 韩语语法学习任务树]] 勾选真正通过的叶子任务。[[13 拆句练习册——从短句到长句]] 用于周测与记录真实材料。

需要逐篇辅导时，可以直接用这个提示：

> 带我学习 korean 中的第 XX 篇。我日语基础不错，请先用日韩对照解释一组核心结构，再给三句韩语让我拆解。先不要给答案，等我回答后指出结构误判，再给一道新题检验迁移。最后把我的错点与通过情况写入练习册；只有满足任务验收条件才更新任务树。
