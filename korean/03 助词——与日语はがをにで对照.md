# 助词——与日语はがをにで对照

目标：让日语助词直觉先帮你定位，再用韩语具体用法校正。

## 高频表

斜线两侧通常是“有收音／无收音”的选择；`(으)로` 另有 ㄹ 例外。

| 韩语 | 功能 | 日语近似 | 例子 |
|---|---|---|---|
| 은／는 | 话题、对比 | は | 책은／영화는 |
| 이／가 | 主语等 | が | 책이／친구가 |
| 을／를 | 宾语 | を | 책을／영화를 |
| 에 | 时间、目标、存在地点等 | に | 세 시에、학교에 가요 |
| 에서 | 动作地点、起点等 | で／から | 집에서 공부해요 |
| 에게／한테 | 人的接受方等；한테 常见于口语 | に | 친구한테 줘요 |
| 의 | 所属、名词间关系 | の | 친구의 책 |
| 도 | 也 | も | 저도 |
| 만 | 只 | だけ | 하나만 |
| 부터／까지 | 从／到 | から／まで | 오늘부터 내일까지 |
| 하고、(이)랑、와／과 | 和、与 | と | 친구하고；책과 영화 |
| (으)로 | 方向、工具、方式等 | へ／で | 버스로、한국어로 |

`와` 接无收音名词，`과` 接有收音名词。`로` 接无收音或 ㄹ 收音，其他收音用 `으로`：`학교로、서울로、집으로`。不要把所有斜线表都套成同一种顺序。

## 은／는 与 이／가

**저는 학생이에요.** 我是学生。／私は学生です。  
**제가 할게요.** 我来做。／私がやります。

`는` 可以把“我”设为话题；`가` 可以在“谁来做”的语境中突出承担者。但“旧信息＝는、新信息＝가”只是入门线索，不能覆盖对比、嵌套从句与其他语境。

**저는 시간이 없어요.** 我没有时间。／私は時間がありません。

这里 `저는` 是话题，`시간이` 是“不存在”的主语。同一句能有话题和主语，不必选一个删掉。

## 에 与 에서：最值得先练的区别

- `학교에 있어요.` 在学校。／学校にいます。存在地点。
- `학교에서 공부해요.` 在学校学习。／学校で勉強します。动作地点。
- `학교에 가요.` 去学校。／学校に行きます。移动目标。

日语的“で”还可能是工具；`버스로 가요` 是乘公交去，不能套成 `버스에서 가요`。

## 助词能叠加，也能替换

`학교에서도`＝在学校也；`학교에서는`＝在学校这个场景下／与别处对比。`저도` 通常用 도 取代原本可能出现的主格或话题标记。不是每个名词都必须再跟一个 이/가。

影音里宾语助词、话题助词常被省略：`나 이거 봤어.` 我看过这个。先学完整结构，再识别省略。`이거` 本身是“这个”，不把末尾 거 当助词。

## 自测

1. 填空：`도서관___ 있어요.`／`도서관___ 책을 읽어요.`（도서관 图书馆，읽다 读）
2. `저는 한국어도 공부해요.` 中 도 强调哪一项？
3. “用韩语说”为什么是 `한국어로 말해요`？

<details><summary>参考答案</summary>

1. 에／에서：存在地点／读书动作地点。
2. 韩语也是学习对象，常暗示还学其他语言；不是“我也”。
3. 로 标记语言／方式；한국어 无收音。日语近似：韓国語で話します。

</details>
