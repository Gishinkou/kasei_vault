# 时态否定与存在——句尾里的事实

目标：听出“做／做了／打算做／没做／做不了”的差别。

## 时间不只靠一个词尾

| 形式 | 例子 | 日语近似 |
|---|---|---|
| 非过去 -아/어요 | 오늘 가요. | 今日行きます。 |
| 过去 -았/었어요 | 어제 갔어요. | 昨日行きました。 |
| -고 있어요 | 지금 먹고 있어요. | 今食べています。 |
| -(으)ㄹ 거예요 | 내일 갈 거예요. | 明日行くつもりです／行くでしょう。 |

非过去也可配明天：`내일 가요`；`갈 거예요` 也可以是推测，不是只能表确定计划。`-겠-` 见 [[10 引用推测与意图——句子套句子]]。

过去形使用与 -아/어 类似的元音选择：`먹다 → 먹었어요`，`보다 → 보았어요 → 봤어요`，`하다 → 했어요`。字面上多个音节可能缩成一个，听力时认整个 `봤어요／했어요` 比临时拼接更快。

## 存在与拥有

- `집에 있어요.` 在家。／家にいます。
- `시간이 있어요.` 有时间。／時間があります。
- `시간이 없어요.` 没有时间。／時間がありません。
- `저는 학생이 아니에요.` 我不是学生。／私は学生ではありません。

있다／없다 同时覆盖日语いる／ある相关用法，不按日语的有生命／无生命直接分成两套。名词身份否定用 아니다，不用 없다。

## 两条否定轴

| 形式 | 例子 | 重点 |
|---|---|---|
| 안＋谓语 | 안 가요. | 不去／没去，要结合时态 |
| -지 않다 | 가지 않아요. | 长形式否定 |
| 못＋动作谓语 | 못 가요. | 不能／未能去 |
| -지 못하다 | 가지 못해요. | 长形式“不能／未能” |

`안 갔어요` 没去；`못 갔어요` 没能去。不要把安／못的听感忽略掉，它们可能彻底改变句意。

常见 하다 动词：`공부 안 해요` 不学习，`공부 못 해요` 没法学习。`안 좋아요` 不好；不要为了表示“不好”机械改为 못 좋아요。

长形式否定的过去可以落在后项：`먹지 않았어요`＝没吃。拆分：`먹-지 / 않-았-어요`。

## -ている 不能整体搬过来

`먹고 있어요` 可以表示正在吃；`앉아 있어요` 表示坐着，偏向动作后状态的持续。`입고 있어요` 可以表示穿着衣服，属于 -고 있다 也能表达结果持续的情形。不要规定“-고 있다 永远是进行，-아/어 있다 永远对应所有结果状态”。

官方核查：[国立国语院关于 -고 있다 的答复](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=&pageIndex=1&qna_seq=334084)说明其可表达动作进行或结果持续。

## 自测

1. 区分：`안 봤어요`／`못 봤어요`。
2. `학생이 없어요` 与 `학생이 아니에요` 各说了什么？
3. 拆分 `공부하고 있어요`，主句谓语是否只是 공부하다？

<details><summary>参考答案</summary>

1. 没看／没能看，前者未明确说明能力或条件障碍。
2. 没有学生／不是学生。后一句主语常由语境补出。
3. 공부하-고／있-어요；完整谓语结构包含辅助性的 있다，表示正在学习。

</details>
