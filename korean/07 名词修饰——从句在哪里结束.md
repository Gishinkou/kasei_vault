# 名词修饰——从句在哪里结束

目标：把长串的“……的东西”当成一个名词块。

## 与日语最重要的差别

日语直接用动词形修饰：`食べる人／食べた料理`。韩语要看专门的修饰词尾：`먹는 사람／먹은 음식`。共同点是修饰语在名词前；具体变化不相同。

| 类型 | 韩语 | 日语近似 |
|---|---|---|
| 动作当前／习惯 -는 | 먹는 사람 | 食べる人／食べている人 |
| 动作已发生 -(으)ㄴ | 먹은 음식 | 食べた料理 |
| 预期／未实现等 -(으)ㄹ | 먹을 음식 | 食べる予定の料理／これから食べる料理 |
| 形容词当前 -(으)ㄴ | 좋은 영화、예쁜 꽃 | いい映画、きれいな花 |
| 名词判断 -인 | 학생인 친구 | 学生である友達 |
| 있다／없다 系常见 -는 | 재미있는 영화 | 面白い映画 |

这里的时间标签只是入门近似。`-(으)ㄹ` 还有预期、可能等含义；`-던、-았/었던` 可表达回顾等，第二轮再学。

注意：`먹은` 是动词吃的过去／完成方向；`좋은` 却是“好”的当前状态。不能把所有 은／ㄴ 都当成过去。

## 边界在哪里

**[친구가 추천한] 영화를 봤어요.**  
日语：友達が勧めた映画を見ました。

```text
친구가 / 추천하-ㄴ / 영화-를 / 보-았-어요
从句主语 / 修饰词尾 / 整个名词块的中心＋宾语助词 / 主句谓语
```

`영화` 是修饰块的落点；`를` 标记的是整个 `친구가 추천한 영화`，不是只有光秃秃的 영화。

**[한국어를 배우는] 친구가 있어요.**  
日语：韓国語を習っている友達がいます。主句是“朋友存在”，不是“我学习”。`한국어를` 属于前面的修饰小句。

## 不要见 는 就判断“は”

- `친구는`：名词＋话题助词。
- `배우는 친구`：动词词干＋修饰词尾＋名词。
- `친구는 한국어를 배우는 사람이에요.`：两种 는 同时出现。

核查：[官方词典 는 检索](https://krdict.korean.go.kr/eng/dicMarinerSearch/search?mainSearchWord=%EB%8A%94)分别列有助词与修饰词尾的条目。

## 自测

1. 分块并找主句谓语：`제가 어제 산 책은 재미있어요.`（사다 买；재미있다 有趣）
2. `갈 곳` 是“去过的地方”吗？（곳 地方）
3. `좋은 사람` 的 좋은 为什么不是过去？

<details><summary>参考答案</summary>

1. `[제가 어제 산] 책은 / 재미있어요`：我昨天买的书很有趣；산＝사＋ㄴ，主句谓语 재미있어요。
2. 通常是要去／可去的地方。去过的地方还需其他结构，如 가 본 곳；不能仅凭 갈 译成去过。
3. 좋다 是形容词，当前名词修饰用 -(으)ㄴ。

</details>
