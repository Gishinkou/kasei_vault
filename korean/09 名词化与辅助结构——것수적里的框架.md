# 名词化与辅助结构——것수적里的框架

目标：把“做某事、能做、做过、应该做”等当成组合结构。

## 것 与 -기：把动作变成可谈论的对象

日语 `映画を見ること／の` 可以帮助理解韩语 `영화를 보는 것`。但韩语不把词典形原封不动放在 것 前面，而用修饰词尾。

**[한국어를 배우는 것]이 재미있어요.**  
学习韩语很有趣。／韓国語を習うことは楽しいです。

```text
한국어를 배우-는 / 것-이 / 재미있어요
修饰小句 / “事情”名词＋主格 / 主句状态谓语
```

`-기` 是另一种常见名词化：`한국어를 배우기가 어려워요` 学韩语很难；`읽기、듣기` 可表示阅读、听力。것 与 기 有各自的习惯接续，不是所有语境都可互换。

关联日语笔记：[[08 「こと」等的基本用法]]；它能提供功能直觉，但不能决定韩语选哪种名词化。

## 三个常见依存名词

| 结构 | 拆法与意义 | 日语近似 |
|---|---|---|
| -(으)ㄹ 수 있다／없다 | 갈＋수＋있다：能去／不能去 | 行くことができる／できない |
| -(으)ㄴ 적이 있다／없다 | 가 본＋적＋있다：有／没有去过的经历 | 行ったことがある／ない |
| -(으)ㄹ 것이다 | 갈＋것＋이다：预期、计划、推测等 | 行くつもりだ／行くだろう |

`수、적、것` 不能只按“方法／时候／东西”的孤立词义硬译；它们在固定框架里承载语法功能。

常见口语变化：`것 → 거`，所以 `갈 것이에요 → 갈 거예요`；`하는 것이 → 하는 게`，`하는 것을 → 하는 걸`。参见 [[11 影音口语——缩约省略与句尾语气]]。

## 一批高收益组合

| 结构 | 示例 | 日语近似 |
|---|---|---|
| -고 싶다 | 가고 싶어요. 想去 | 行きたい |
| -아/어 보다 | 먹어 봤어요. 尝过了 | 食べてみた |
| -아/어 주다 | 도와주세요. 请帮忙 | 助けてください |
| -아/어야 하다／되다 | 가야 해요. 必须去 | 行かなければならない |
| -아/어도 되다 | 가도 돼요. 可以去 | 行ってもいい |
| -(으)면 안 되다 | 가면 안 돼요. 不可以去 | 行ってはいけない |
| -기로 하다 | 가기로 했어요. 决定去 | 行くことにした |
| -게 되다 | 알게 됐어요. 后来知道了 | 知るようになった |

“不必去”与“不能去”不同：`안 가도 돼요` 是不去也可以；`가면 안 돼요` 是去不行。先抓否定所在的层级，再译中文。

## 自测

1. 拆 `한국에 가 본 적이 있어요`。（한국 韩国）
2. `먹어 봤어요` 的 봤어요 是“看了”吗？
3. 区分 `안 해도 돼요` 与 `하면 안 돼요`。

<details><summary>参考答案</summary>

1. `한국에 / 가 보-ㄴ / 적-이 / 있-어요`：有去韩国的经历；主句谓语 있어요，가 보다 提供尝试／经验含义。
2. 这里 보다 是“试着做”的辅助用法，整句是尝过／试着吃过，不是看吃东西。
3. 不做也可以／不可以做。

</details>
