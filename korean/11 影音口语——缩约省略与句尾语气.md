# 影音口语——缩约省略与句尾语气

目标：知道为什么已经会拆字幕，却还是听不出对白。

## 先建立声音中的整体块

| 常见口语形式 | 对应完整形式／分析 | 功能 |
|---|---|---|
| 난／넌 | 나는／너는 | 我呢／你呢 |
| 전／절 | 저는／저를 | 礼貌“我”＋话题／宾语 |
| 이건／이걸 | 이것은／이것을 | 这个＋话题／宾语 |
| 게／걸 | 것이／것을 | 名词化块接主格／宾格时常见 |
| 거예요 | 것이에요 的口语形式 | 判断；常嵌在计划／推测框架 |
| 뭐 | 무엇 | 什么 |
| 왜요? | 为什么＋礼貌标记 | 不含显式动作谓语也可成立 |
| 간대요 | 간다고 해요 | 转述“去” |

表中的形式不总能脱离上下文唯一还原。`게` 还可能是 `-게` 词尾；`걸` 也可能出现在别的句末结构。用相邻词与句子功能判断。

## 五种高频语气

| 词尾／结构 | 示例 | 首轮抓什么 |
|---|---|---|
| -죠（-지요） | 그렇죠. 是吧／对啊 | 确认、共享认识等 |
| -잖아요 | 알잖아요. 你知道的嘛 | 提醒对方某个认识 |
| -거든요 | 내일 시험이 있거든요. 因为明天有考试嘛 | 句末补充理由、背景 |
| -네요 | 좋네요. 真不错啊 | 新发现、感叹等 |
| -는데요 | 지금 바쁜데요. 我现在有点忙…… | 背景、委婉回应、期待后话等 |

句末 `-거든요` 与小句连接 `-거든` 的条件用法不应混为一谈。也不要把语气词固定翻译为一个中文“啊”，它可能改变说话人的态度。

## 完整结构怎样缩成对白

`저는 이 영화를 봤어요. → 저 이 영화 봤어요. → 나 이거 봤어.`

这里展示三种可能表达，不是必经的缩约链。最后一句连人称的礼貌层级、指示词和语体都变了。日语功能近似：私、この映画見ました。／これ見た。

**봤는데 기억이 안 나요.** 看过，但是想不起来。  
拆：`보-았-는데 / 기억-이 / 안 / 나-요`。前后主语通常省略，`기억이 나다` 是“想起”的常用搭配，不要只按“记忆出来”逐词猜。

## 一个 60—90 秒片段的输入循环

1. 无字幕听一次，记人物、场景和大致立场，不暂停查词。
2. 开韩文字幕／可靠逐字稿，选 3—5 句；每句先圈谓语，再划助词与从句。
3. 每句最多查三个关键生词。字幕若只是画面摘要，不把它当逐字稿。
4. 看字幕听两遍，再关字幕听两遍；重点匹配本周目标词尾。
5. 只摘一条能复用的结构，按 [[13 拆句练习册——从短句到长句#真实影音记录模板|记录模板]] 保存。

当天精听后能听懂，可能来自对内容的记忆。隔 48 小时用另一段同类型材料检验迁移；先精听，再用已能理解的大意材料作轻松泛听。

## 自测

1. `제가 하는 게 좋아요` 中 게 可怎么展开？
2. `나 이거 안 봤어` 没有 를，还能判断对象吗？
3. “字幕看懂、声音不懂”最先补什么？

<details><summary>参考答案</summary>

1. `제가 하는 것이 좋아요`：我来做比较好等，具体含义依上下文。
2. 能，이거 是看这个的对象，宾语助词省略；是否没看过或某次没看需看语境。
3. 查明问题是音变／缩约／语速边界，做短句音频与文本对齐；单纯再背词义未必解决。
