# 谓语活用——词干与词尾积木

目标：看到一个变化后的谓语，知道哪里是词义，哪里是语法。

## 三层积木

```text
词干 ＋ 中间词尾（敬语／时态／情态等） ＋ 末端词尾
먹- ＋ -었- ＋ -어요 → 먹었어요（吃了）
오- ＋ -시- ＋ -었- ＋ -어요 → 오셨어요（来了，尊敬主语）
```

这里是学习用拆分；实际拼写会缩约。词典形 `먹다` 去掉 다 得 `먹-`，`보다 → 보-`，`하다 → 하-`。韩语不是先套日语五段／一段分类，再做同样的变化。

词尾常见三个出口：`먹어요` 结束句子，`먹고` 连接小句，`먹는` 修饰后面的名词。先判断出口，比背全部名称更有用。

## 最先掌握 -아／어요

对规则词干，末音节元音为 ㅏ 或 ㅗ 时通常取 아요，其他通常取 어요；하다 系取 해요。元音相接常合并或缩约。

| 词典形 | 词干＋形式 | 常见结果 | 日语 |
|---|---|---|---|
| 먹다 | 먹＋어요 | 먹어요 | 食べます |
| 가다 | 가＋아요 | 가요 | 行きます |
| 보다 | 보＋아요 | 봐요 | 見ます |
| 마시다 | 마시＋어요 | 마셔요 | 飲みます |
| 배우다 | 배우＋어요 | 배워요 | 習います |
| 하다 | 하＋여요 | 해요 | します |
| 좋다 | 좋＋아요 | 좋아요 | いいです |

`-아/어` 家族还会出现在 `-아/어서、-아/어도、-아/어야、-아/어 보다` 中。这是一组可复用的接续底座；요 并不是所有结构都要带。

## (으) 与 ㄹ 记号怎么看

`-(으)면`：通常有收音用 으면，无收音用 면：`먹으면、가면`；ㄹ 收音直接接 면：`살면`。

`-(으)ㄹ`：`가다 → 갈`，`먹다 → 먹을`；ㄹ 收音如 살다 保持 `살`。这里的 ㄹ 是写进音节块的辅音，不是另读一个“리을”音节。

## 先认常见变形，不急着穷尽

| 类型 | 例子 | 阅读时还原 | 边界 |
|---|---|---|---|
| ㄷ 类不规则 | 듣다 → 들어요 | 듣다，听 | 받다 → 받아요 是规则变化 |
| ㅂ 类不规则 | 춥다 → 추워요 | 춥다，冷 | 입다 → 입어요 是规则变化 |
| 르 类不规则 | 모르다 → 몰라요 | 모르다，不知道 | 不是所有含 르 词都如此 |
| ㅡ 脱落 | 쓰다 → 써요；바쁘다 → 바빠요 | 写／忙 | 元音选择需看词干结构 |
| ㄹ 脱落 | 살다 → 사는、삽니다 | 살다，居住／生活 | ㄹ 在部分辅音词尾前脱落 |
| ㅎ 类不规则 | 그렇다 → 그래요 | 그렇다，是那样 | 좋다 → 좋아요 不属此变化 |

这些变化取决于具体词与接续环境，不是“看到这个收音就必变”。词典的“活用”栏是最省力的核对方法。

## 名词判断单独认识

`학생이다 → 학생이에요`（有收音）；`친구이다 → 친구예요`（无收音）。否定是 `학생이 아니에요`。形容词 `좋아요` 不需要再加 이에요。

## 自测

1. `공부해요、봤어요、들어요` 分别还原什么词典形？
2. 为什么 `가는 사람` 的 는 不是话题助词？
3. 变成 -아요/어요：먹다、보다、하다。

<details><summary>参考答案</summary>

1. 공부하다（学习）、보다（看，봤어요 是过去）、듣다（听）。
2. 는 接在动词词干 가- 后，把动作变成名词修饰语；整块是“去的人”。
3. 먹어요、봐요、해요。

</details>
