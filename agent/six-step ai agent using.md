# 六步骤 ai 编码

| 文件              | 阶段    | 作用                             |
| --------------- | ----- | ------------------------------ |
| `requirements/` | 开工前   | 把口头需求变成明确的背景、目标、验收标准           |
| `designs/`      | 编码前   | 明确方案、明确文件变更清单                  |
| `test-plans/`   | 编码前/中 | 测试驱动开发：先定义测试契约，再让 AI 编码        |
| `reviews/`      | 编码后   | 记录 Review 发现、正确做法、是否需要更新 skill |
| `ai-sessions/`  | 收尾    | 记录本轮 AI 协作过程、关键决策、可复用模式        |
| `bugfixes/`     | 有问题时  | 记录模式性错误或较重排障，作为后续 AI 参考材料      |
|                 |       |                                |
