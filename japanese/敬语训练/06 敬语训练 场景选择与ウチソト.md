# 敬语训练 场景选择与ウチソト

目标：把礼貌模式绑在“我现在是什么角色”，而不是一遇到日本人就紧张。

## 为自己设置几个默认场景

| 场景 | 本教程的初始选择 | 之后如何调整 |
|---|---|---|
| 熟悉朋友的私人聊天 | 已有关系允许的普通体 | 不因学敬语而永久改掉亲近语体 |
| VRChat 初次见面 | 轻松的です／ます | 对方明确邀请或双方自然建立熟悉关系后再调整 |
| 商店、餐厅、窗口的顾客 | 简洁的です／ます＋お願いします | 不照搬店员的接待语 |
| 社区、房东、较不熟悉的同事 | です／ます，必要时尊敬语 | 看当地习惯、职责与关系 |
| 面试、初次商务联系 | 稳定的です／ます＋关键敬语 | 随具体组织与对方互动微调 |

这是可用于起步的选择，不是仅靠年龄就能推出的固定规则。对方先用普通体，不一定要求你立刻同样切换；继续礼貌回应通常仍可成立。

## 如何切到普通体

`よかったら、敬語なしで話しませんか。`  
`私はタメ口でも大丈夫です。`  
`じゃあ、少しずつタメ口で話しますね。`

不是必须举行仪式才能切换；这些句子适合你拿不准时。对方说 `タメ口でいいよ` 后，也不用一瞬间把所有です／ます清空。

朋友问“怎么突然这么客气”时，直接解释：`今日は敬語の練習をしているんです。距離を置きたいわけではないですよ。` 训练结束后回到原来的聊天方式。

## ウチ／ソト随着说话对象变化

公司内部对上司：`田中部長は、いらっしゃいますか。`

向客户介绍自己公司的上司：`部長の田中は、ただいま席を外しております。`

第二句把田中作为自己公司一侧的人，对外通常不用田中部長＋いらっしゃる去抬高自己侧。`部長の田中` 仍能保留其职务信息，重点不是粗鲁地直呼其名。

对普通外人谈自己家人，先练 `父、母、兄、姉`；对别人家人可能用 `お父様、お母様`，日常也有更轻松形式。情境与习惯不同，不把家庭里的呼称原样搬到正式介绍。

依据：[文化庁 ウチ／ソト解说](https://www.bunka.go.jp/seisaku/kokugo_nihongo/kokugo_shisaku/keigo/chapter7/detail.html)。关联 [[21 管理者如何称呼下属——日语职场常用词汇]]。

## 尊重还体现在内容选择

不用反复称对方あなた，通常用名字／职称或省略。初次见面少作没有依据的年龄、职业、收入假设；问个人信息时让对方容易拒绝。礼貌动词不能替代这些判断。

## 场景自测

1. 朋友扮演店员，对你说“お待たせいたしました”。你是否需要回“かしこまりました”？
2. 向客户解释自己公司的经理出去了，如何说？
3. 新认识的人一直用普通体，你是否必须马上跟着切换？

<details><summary>参考答案</summary>

1. 不需要。可以说 `ありがとうございます`，再回答当前事项。かしこまりました更像承接要求，不是通用礼貌问候。
2. `弊社の田中は、ただいま外出しております。` 需要职务时 `部長の田中は…`。
3. 不必须。先保持轻松的です／ます，结合关系发展决定。

</details>

验收：五张场景卡分别说明自己角色、对方角色和默认语体；至少解释一例ウチ／ソト变化。
