# 敬语训练 尊敬谦让与丁重的方向

目标：先判断关系方向，再选敬语词；不靠“哪个更高级”的感觉乱换。

## 每句先问三个问题

1. 谁在做动作？
2. 动作涉及／指向谁？
3. 我正向谁说话？

例如对面试官说“我读过贵公司的资料”：行动者是我，阅读对象是对方提供的资料，听者是面试官。可说 `御社の資料を拝見しました`。换成“面试官读我的资料”，不能继续用拝見する作对方的动作。

## 五类的功能

| 类别       | 核心作用                   | 例子          |
| -------- | ---------------------- | ----------- |
| 丁寧語      | 对听者礼貌地说                | 読みます、学生です   |
| 尊敬語      | 尊重所谈到的行动者／人物           | 先生がいらっしゃいます |
| 謙譲語Ⅰ     | 表述自己一方涉及对方的动作，尊重动作相关对象 | 先生に伺います     |
| 謙譲語Ⅱ／丁重語 | 把自己一方的行为对听者说得郑重        | 私は明日京都に参ります |
| 美化語      | 让表达较文雅，有惯用范围           | お茶、お料理      |

依据：[文化庁 敬语基本解说](https://www.bunka.go.jp/seisaku/kokugo_nihongo/kokugo_shisaku/keigo/chapter2/detail.html)。首轮能辨别前三条关系即可，不要求每句话都口头报分类。

### Ⅰ与Ⅱ为什么值得分开

`先生の研究室に伺います`：拜访老师，老师是动作涉及的敬意对象。

`明日、京都に参ります`：对听者郑重说自己的行程；京都并不是被尊敬的人。若只是去商场，日常说 `明日、買い物に行きます` 就足够，不必练成每次都参ります。

官方解释见 [文化庁 謙譲語Ⅰ与Ⅱ](https://www.bunka.go.jp/seisaku/kokugo_nihongo/kokugo_shisaku/keigo/chapter6/detail.html)。它帮助避免“自己的任何行动都套伺う”。

## 丁寧与尊敬可以组合

- `先生が来ます`：主句对听者礼貌，没用专门尊敬词。
- `先生がいらっしゃる`：尊敬老师，主句仍是普通体。
- `先生がいらっしゃいます`：尊敬老师＋对听者礼貌。

熟悉朋友间聊老师时，尊敬语仍可能出现；正式场景谈自己时，句尾仍要礼貌。两个维度不能合成一条“ます越多越尊敬”的轴。

## 授受结构也看方向

`先生が説明してくださいました`：老师给我说明，老师是行动者。  
`先生に説明していただきました`：我接受老师的说明，从受益者视角说。

`いただく` 不表示“所有句子的主语都应写我”；完整句常省略受益者。听力要把省略关系恢复出来。具体动词见 [[05 敬语训练 常用动词与接续]]。

## 口头自测

1. 面试官说了某个要求，应描述“面试官が申しました”还是“おっしゃいました”？
2. 我明天去老师办公室，选行きます、伺います、いらっしゃいます中的哪些可用？
3. 店员说“こちらでお待ちしております”，等待的人是谁？

<details><summary>参考答案</summary>

1. おっしゃいました；申す是自己一方的丁重表达，不能这样抬高面试官。
2. 行きます是基本礼貌；伺います在拜访老师的语境适用；不能用いらっしゃいます来尊敬自己。
3. 店员或店方一侧在等待，对顾客郑重说明；不是要求顾客等候。要求等候通常是少々お待ちください。

</details>

验收：五个新场景能说清行动者、相关对象、听者，至少四个选择正确，再练词表。
