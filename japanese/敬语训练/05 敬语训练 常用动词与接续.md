# 敬语训练 常用动词与接续

目标：先掌握十来个会反复听到、确实用得到的形式，保证方向正确。

## 常用词表

“自己侧”一栏是可选表达，须满足动作关系；不是看到普通词就强制替换。

| 普通表达 | 对方／需尊重者的动作 | 自己侧的相关表达 |
|---|---|---|
| 行く／来る／いる | いらっしゃる | 行く／来る：参る；拜访：伺う；いる：おる |
| 言う | おっしゃる | 自称／郑重说：申す；向人陈述：申し上げる |
| する | なさる | いたす |
| 見る | ご覧になる | 拝見する，尤其查看对方的资料等 |
| 聞く／尋ねる | お聞きになる | 伺う，向对方听取／询问 |
| 会う | お会いになる | お目にかかる |
| 食べる／飲む | 召し上がる | いただく |
| 知っている | ご存じだ | 存じている；尊重所知人物时如存じ上げている |
| くれる | くださる | 从接受视角用いただく |
| もらう | 受け取る等的敬语依动作选择 | いただく |

先主动说：`申します、伺います、拝見しました、いたします、ありがとうございます`。其余先听懂，之后按场景扩展。日常看电影完全可以说 `映画を見ました`，不必总用拝見しました。

## おっしゃる・いらっしゃる：是什么，放在敬语体系的哪一层

两者都是**尊敬語的专门动词形式**，用于尊重动作或状态的主体。可以是直接交谈的对方，也可以是谈到的老师、顾客等第三者；不拿来抬高自己。分类与方向参见 [[04 敬语训练 尊敬谦让与丁重的方向]]；依据：[文化庁 敬语基本解说](https://www.bunka.go.jp/seisaku/kokugo_nihongo/kokugo_shisaku/keigo/chapter2/detail.html)。

| 词典形 | 对应普通动词 | 中文理解 | 常用礼貌形 |
|---|---|---|---|
| おっしゃる | 言う（いう） | 说、讲；以尊敬的方式描述某人说话 | おっしゃいます |
| いらっしゃる | 行く／来る／いる | 去／来／在；具体意思看上下文 | いらっしゃいます |

### おっしゃる：尊重“说话的人”

| 例句 | 中文意思 | 还原成普通动词 |
|---|---|---|
| 先生は何とおっしゃいましたか。 | 老师说了什么？ | 何と言いましたか |
| おっしゃるとおりです。 | 正如您所说。 | 言うとおりです |
| 先ほどおっしゃった件ですが…… | 关于您刚才说的那件事…… | 先ほど言った件 |

`おっしゃる` 中的小「っ」要留一拍停顿；不要读成「おしゃる」。`おっしゃった` 是过去普通形，`おっしゃいました` 是过去礼貌形。

说自己的话时用 `私はそう言いました`；对听者郑重陈述可用 `申しました`，向需要尊重的人陈述可用 `申し上げました`，须按关系选择。不要说 `私はそうおっしゃいました`。

### いらっしゃる：一个词对应“去、来、在”

| 例句 | 此处的意思 | 还原成普通动词 |
|---|---|---|
| 明日は京都へいらっしゃいますか。 | 您明天去京都吗？ | 京都へ行きますか |
| 明日は何時にこちらへいらっしゃいますか。 | 您明天几点来这里？ | こちらへ来ますか |
| 先生は今、研究室にいらっしゃいます。 | 老师现在在研究室。 | 研究室にいます |

不要把 `いらっしゃる` 固定翻成“来”。先看目的地、当前所在位置、时间和说话视点；`へ／に` 能提供线索，但单靠助词不能确定去还是来。

`〜ていらっしゃる` 还可以对应 `〜ている`，尊重正在做某事或处于某种状态的人：

- `先生は今、本を読んでいらっしゃいます。` → 老师现在正在读书。普通礼貌说法：`読んでいます`。
- `どちらに住んでいらっしゃいますか。` → 您住在哪里？普通礼貌说法：`住んでいますか`。

店员的 `いらっしゃいませ` 是固定的欢迎用语，通常理解为“欢迎光临”，无需按“去／来／在”逐字翻译。

### 为什么加不加ます都属于尊敬语

```text
言う → 言います                     对听者礼貌
言う → おっしゃる                   尊重说话的人，句末是普通体
言う → おっしゃいます               尊重说话的人＋对听者礼貌

いる → います                       对听者礼貌
いる → いらっしゃる                 尊重所在的人，句末是普通体
いる → いらっしゃいます             尊重所在的人＋对听者礼貌
```

因此 `おっしゃるとおりです` 中，`おっしゃる` 已经承担尊敬作用，整句由 `です` 收成礼貌体；不能把从句也机械改为 `おっしゃいますとおりです`。两词都是以る结尾的特殊五段动词，不按一段动词“去る加ます”处理；常用接续见下面。

## 五个ます型不要临时推导

`いらっしゃる → いらっしゃいます`  
`おっしゃる → おっしゃいます`  
`なさる → なさいます`  
`くださる → くださいます`  
`ござる → ございます`

这些常见词在ます接续中有特殊变化。不要说“いらっしゃります”。`いらっしゃいませ` 是接待惯用句，顾客不需要照着回应同一句。

## 两个生产性框架

- 尊敬：`お＋连用形＋になる`，如 `お読みになる、お帰りになる`；汉语动词常见 `ご利用になる`。
- 谦让：`お＋连用形＋する`，如 `お届けする、お持ちする`；汉语动词如 `ご案内する、ご説明する`，需要有适合尊重的相关对象。

框架不覆盖所有动词；已有专门形式如 `ご覧になる` 优先整块记。不造“お見るになる”，也不把所有汉语词都加ご。

`説明します → ご説明します → ご説明いたします` 可在向对方说明的正式场景使用；纯粹讲自己的某项操作，`操作しました` 就很清楚。

## 日常动作变成服务与业务概念

### 使う → 利用する → ご利用になる：分清两次变化

你可能观察到：接待表达不总是把日常动词直接变成敬语，也常先换成适合服务场景的汉语词。这是很有用的听辨线索。

```text
使う → 利用する           选词：把行为描述为“使用某项服务／设施”
利用する → ご利用になる  敬语：尊重利用该服务的行动者
```

`利用する` 本身不是尊敬语：`私は毎日このアプリを利用しています` 是普通的丁寧体。也可以不换词，直接说尊敬形式 `お使いになる`。正式汉语词与敬语构文是两层，不能合并成“这个词天然更尊敬”。

### 利用的概括范围与损失的信息

| 具体动作 | 从服务角度描述 | 留意 |
|---|---|---|
| バスに乗る | バスを利用する | 把“乘坐”放进交通服务使用的框架 |
| ATMでお金を下ろす | ATMを利用する | 只保留使用ATM，未说明取款还是其他操作 |
| ホテルに泊まる | ホテルを利用する | 泛指使用酒店；强调住宿时用宿泊する更准确 |
| アプリを使う | アプリを利用する | 适合功能与服务说明，不必日常一律换词 |

所以 `当店をご利用いただき、ありがとうございます` 可以覆盖来店消费等多种行为；但“覆盖得广”也意味着没具体说顾客点了什么、买了什么。要理解或说明细节，仍需听对象与具体动作。

### 同类词汇：先认业务动作，再认敬语包装

下表是场景近似对应，不是所有句子都能直接互换；括号标出重点。

| 日常说法／意图 | 服务或业务词 | 常见表达 |
|---|---|---|
| 買う | 購入 | ご購入ありがとうございます。 |
| 料理を頼む | 注文 | ご注文はお決まりですか。 |
| 席や部屋を事前に取っておく | 予約 | ご予約はございますか。 |
| 泊まる | 宿泊 | ご宿泊のお客様はこちらへどうぞ。 |
| 店に来る | 来店 | ご来店ありがとうございます。 |
| お金を払う | 支払い | お支払いはカードですか。 |
| 受け取る | 受け取り | こちらでお受け取りください。 |
| 書類などを見せる | 提示 | 身分証をご提示ください。 |
| 用紙の欄に書く | 記入 | お名前をご記入ください。 |
| 内容が合っているか確かめる | 確認 | 内容をご確認ください。 |
| 不明点を聞く／対応を求める | 問い合わせ | 詳しくは窓口へお問い合わせください。 |
| 困りごとを話して助言を求める | 相談 | 担当者にご相談ください。 |
| 場所や手順を教える／連れていく | 案内 | 私がご案内します。 |
| 理由や仕組みを詳しく話す | 説明 | 手順をご説明します。 |

`記入` 是向指定栏填写，不是写文章的万能替代；`提示` 是出示，不是看电影；`注文` 也不是所有“頼む”。先保留动词意义，再选与对象相符的业务词。

### ご＋动作词，并不能独自告诉你方向

同一个 `確認`，看后面的构文才知道谁做：

- `ご確認ください`：请你确认。
- `ご確認いただけますか`：请你确认，可以吗？从请求者受益的视角说。
- `私が確認します`：我确认，基本礼貌表达。
- `私が内容をご説明します`：我向你说明，用自己的行动尊重相关对象。
- `お客様からのご説明`：顾客作出的说明；`お客様へのご説明`：向顾客作出的说明。同样的ご説明，关系不同。

文化庁明确区分了“对方作出的御説明”与“自己向对方作出的御説明”：不能仅凭ご就判成尊敬语。参见 [敬语基本解说](https://www.bunka.go.jp/seisaku/kokugo_nihongo/kokugo_shisaku/keigo/chapter2/detail.html)。

不要机械制造 `ご＋任何名词`：`お支払い、お受け取り、お問い合わせ` 都是常见形式。先按整块记，熟练后再分析构词。

### 朋友练习：同一个服务，换三种说法

朋友说“バスに乗ります”，你说明它可概括为“バスを利用します”；随后朋友扮演工作人员说 `このバスをご利用ください`，你恢复成“让我乘坐／使用这班公交”。再换成 `このバスはご利用いただけません`，你必须听出“不能乘坐”，而不是只认到公交与利用。

每次做三组：识别业务动作 → 判断行动者／意图 → 用自己身份回复。更多尾部对照见 [[07 敬语训练 服务业听懂路线]]。

## れる／られる：听懂即可，输出先用明确形式

`先生が話されます` 可以是尊敬，但 `れる／られる` 也可能表达被动、可能等。`資料を見られますか` 在不同语境中可能问“能看吗”或“要看吗／看吗”。为了表达明确，问对方是否看过资料可用 `資料はご覧になりましたか`；问权限可用 `この資料を見ることはできますか`。
