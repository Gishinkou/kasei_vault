# 日本旅行服务场景与听辨清单

本页根据我这次旅行涉及的购物、连锁餐饮、居酒屋、缆车、电车、观光巴士、景点与吧台手握寿司，枚举下一轮可练习的服务场景。重点是：**对方在推进哪一步，需要我作什么选择，有什么限制，什么时候结束。**

“料理chain”暂按连锁餐饮理解，包含柜台点餐、食券机、平板点餐、桌边服务等不同形式；不是每家店都有所有步骤。下方日文是学习用的可能表达，不是本次旅行的逐字实录，也不是对所有店家规则的概括。

我作为顾客或游客，默认使用简洁的です／ます、お願いします、ありがとうございます。服务人员使用的整串敬语，先练听懂，不要求对称地照搬。

相关教程：[[05 敬语训练 常用动词与接续]]、[[07 敬语训练 服务业听懂路线]]。和朋友练本页时，用 [[11 敬语训练 VRChat朋友练习指南]] 的角色扮演方法。

## 一、购物：从看商品到带走

| 小场景 | 对方可能说什么 | 要听懂什么／我可以怎么说 |
|---|---|---|
| 询问需求、找商品 | 何かお探しですか。 | 问我找什么；まだ見ているだけです。ありがとうございます。 |
| 查尺码、颜色、库存 | おサイズはおいくつですか。／在庫を確認いたします。 | 确认尺寸或准备查库存；この色で、もう一つ大きいサイズはありますか。 |
| 试穿、试用 | ご試着なさいますか。／こちらでお試しいただけます。 | 是否试穿／可以在这里试用；試着してもいいですか。 |
| 商品有无现货 | こちらはお取り寄せになります。 | 需调货，不是现在一定能拿走；今日、持ち帰ることはできますか。 |
| 收银、付款方式 | お支払い方法はいかがなさいますか。 | 选择付款方式；カードでお願いします。 |
| 袋子、包装、礼品 | 袋はご入用ですか。／ご自宅用ですか。 | 要不要袋子／是否自用；袋は要りません。／プレゼント用です。 |
| 积分、收据、领收书 | ポイントカードはお持ちですか。／領収書はご入用ですか。 | 是否有会员卡／需不需要领收书；持っていません。／領収書をお願いします。 |
| 免税、退换与条件 | 免税をご希望ですか。／返品はお受けできません。 | 问我是否希望免税／说明不能退货；対象になりますか。／交換もできませんか。 |

**易混点**：`お取り寄せ` 调货、`お取り置き` 留货不是同一件事；`レシート` 与 `領収書` 都与付款凭据有关，但店方处理可能不同。免税与退换资格要按当次商品、本人条件和店方说明确认，不能只凭一句ご希望ですか认定符合条件。

## 二、连锁餐饮：从排队到取餐

| 小场景 | 对方可能说什么 | 要听懂什么／我可以怎么说 |
|---|---|---|
| 取号、等位、人数 | 番号札をお取りください。／何名様ですか。 | 是否先取号、几个人；二人です。／ここで待てばいいですか。 |
| 堂食还是外带 | 店内でお召し上がりですか。／お持ち帰りですか。 | 用餐方式；店内でお願いします。 |
| 柜台点餐、套餐选择 | セットになさいますか。 | 是否选套餐；単品でお願いします。 |
| 食券机、平板与注文确认 | 先に食券をお買い求めください。／こちらからご注文ください。 | 下单渠道；食券はどこで買えますか。 |
| 分量、口味与配料 | ご飯の量はいかがなさいますか。 | 饭量等选择；普通でお願いします。／少なめにできますか。 |
| 售罄、替换、等待时间 | こちらは売り切れです。／少々お時間をいただきます。 | 没有货／需要等；では、こちらをお願いします。／何分くらいかかりますか。 |
| 取餐、号码、餐具自助 | ○番でお待ちのお客様。／お水はセルフサービスです。 | 轮到哪个号码／哪些要自取；この番号です。／お水はどこにありますか。 |
| 用餐结束、餐盘与结账 | 食器はこちらにお返しください。／お会計はこちらです。 | 归还餐具或结账地点；ごちそうさまでした。 |

**易混点**：`ご注文は以上でよろしいですか` 是确认“点单就这些吗”，不是说料理全部上完。`食券`、`注文番号`、`番号札` 各自可能对应付款、出餐、等位，不把所有号码混成一个队列。

点餐基本表达参考 [国际交流基金 Erin 第8课](https://www.erin.jpf.go.jp/materials/key-phrases/download/erin_lesson08_key-phrases_explanation_zh.pdf)。

## 三、居酒屋：从入座到最后点单

| 小场景 | 对方可能说什么 | 要听懂什么／我可以怎么说 |
|---|---|---|
| 预约、人数、吧台或桌席 | ご予約はございますか。／カウンター席でもよろしいですか。 | 有无预约／是否接受吧台；予約していません。／カウンターで大丈夫です。 |
| 入座后的饮料 | お飲み物から伺ってもよろしいですか。 | 先点饮料；まず、生ビールを一つお願いします。 |
| お通し、席费等说明 | こちら、お通しです。／お席料を頂戴しております。 | 小菜或座位收费的说明；こちらは料金に含まれていますか。 |
| 单点、套餐、饮放题 | コースになさいますか。／飲み放題はお付けしますか。 | 套餐与饮料方案选择；単品で注文できますか。 |
| 追加点菜、推荐与人数份量 | おすすめはこちらです。／二人前から承ります。 | 推荐与最小份量；二人で食べるなら、どのくらいがよさそうですか。 |
| 盘子、分餐、撤盘 | お取り皿をお持ちします。／お下げしてもよろしいですか。 | 要给小盘／能否撤盘；ありがとうございます。／まだ食べています。 |
| ラストオーダー与限时 | ラストオーダーのお時間です。／お席は二時間制です。 | 最后点单与座位时限；あと一品、注文できますか。 |
| 账单、分开付款、离店 | お会計はご一緒でよろしいですか。 | 是否合并结账；別々にできますか。／一緒でお願いします。 |

**易混点**：`お通し` 不是自动推断为免费招待；店家可能将其作为收费小菜。JNTO 对居酒屋的相关说明见 [旅行礼仪](https://www.japan.travel/en/ca/etiquette/)。具体收费、能否不点、分账方式以当店确认结果为准。

`ラストオーダー` 是最后接受点单的时间，`閉店` 是闭店；不一定发生在同一分钟。`お下げしてもよろしいですか` 是撤盘许可，不是在催你付款。

## 四、主厨面对面的手握寿司：从介绍食材到收尾

| 小场景 | 主厨／店员可能说什么 | 要听懂什么／我可以怎么说 |
|---|---|---|
| 到店、预约与课程 | 本日はおまかせのコースでよろしいですか。 | 确认所订方案；はい、お願いします。 |
| 食物过敏与不能吃的食材 | アレルギーや苦手な食材はございますか。 | 询问身体限制与偏好；○○のアレルギーがあります。／○○が苦手です。 |
| 介绍鱼种、部位与产地 | こちらは○○です。／○○産の○○です。 | 当前是什么，不必句句理解所有修饰；これは何という魚ですか。 |
| 已调味、是否蘸酱油 | 味が付いておりますので、そのままお召し上がりください。 | 已调味，直接吃；このまま食べればいいですか。 |
| 推荐立即吃与吃法 | できれば、お早めにお召し上がりください。 | 希望及时吃，不一定是催全餐结束；はい、いただきます。 |
| 芥末、饭量等调整 | シャリの量はいかがですか。 | 问醋饭量；少なめにしていただけますか。 |
| 感想、轻松交谈 | お口に合いますか。 | 是否合口味；とてもおいしいです。／この魚は初めて食べました。 |
| 追加与课程外项目 | 追加で何か握りましょうか。 | 是否要追加，可能另计费；追加料金はいくらですか。 |
| 最后一贯、握寿司阶段结束 | 握りはこれで最後になります。 | 握寿司到此，未必整个套餐都结束；この後、ほかのお料理もありますか。 |
| 整个课程结束、茶与结账 | お料理は以上でございます。／お茶をお持ちしましょうか。 | 宣布上菜结束／询问茶；ごちそうさまでした。とてもおいしかったです。 |

`シャリ` 指寿司饭，`ネタ` 指鱼料等上面／里面的食材；不理解鱼名时可以问名称，但没有必要为每一贯强行找一个高级评价词。对主厨说具体的 `この食感が好きです`、`香りがいいですね` 即可。

有关寿司与 omakase 的背景可参考 [JNTO 寿司指南](https://www.japan.travel/en/guide/sushi-in-japan/)。本表不是所有店家统一的上菜顺序；某些调整未必能满足，事前说明过敏尤其重要。

### 我的旅行回忆：主厨说“结束”时第一遍没听懂

我的回忆是：上完最后一道菜时，主厨先说了一句表示结束的话，我第一遍没听懂；后来他补充了一句，我记得是 **「これって終わり」**。

这句话按我的回忆保留，不据此认定其逐字发音。第一句原话目前未知；不能倒推为某一种固定敬语。下一轮练习可以对照下面几种**可能出现的表达**，它们不是对当时原话的还原：

| 可能表达 | 主要信息 |
|---|---|
| お料理は以上でございます。 | 料理到此为止 |
| 本日のおまかせは以上となります。 | 今日的 omakase 套餐到此 |
| こちらが最後の一品になります。 | 眼前这一品是最后一道 |
| 握りはこれで最後です。 | 握寿司部分最后，范围更窄 |
| これで終わりです。 | 简单直接说明到此结束，具体指什么由语境决定 |

这里可先听关键词：`以上（いじょう）`、`最後（さいご）`、`一品（いっぴん）`、`終わり（おわり）`，再听范围：`お料理／コース／握り`。`以上` 在收尾句中常表示“就这些”，不能只按数量里的“以上”理解。

我下次可以确认：

- `これでコースは全部ですか。` 套餐全部上完了吗？
- `握りはこれで最後ということですか。` 是说握寿司部分到这里结束吗？
- `この後、まだ何か出ますか。` 后面还会有东西上来吗？

确认完可以说 `ごちそうさまでした。とてもおいしかったです。`，不需要复述 `以上でございます`。主厨改用短句后我能理解，提示下一轮值得补“结束信号与范围”；单次回忆还不能证明困难只来自敬语。

## 五、缆车与山顶设施：从购票到下山

| 小场景 | 对方可能说什么 | 要听懂什么／我可以怎么说 |
|---|---|---|
| 往返、单程与人数 | 往復ですか、片道ですか。 | 票种；大人二人、往復でお願いします。 |
| 排队、下一班、检票 | 次の便までお待ちください。／乗車券を拝見します。 | 等班次／工作人员看票；次は何時ですか。／こちらです。 |
| 上行、下行、站台 | 山頂行きはこちらです。 | 方向，不是所有入口都一样；下りはどこから乗りますか。 |
| 最后一班与下山期限 | 下りの最終便は○時です。 | 回程末班，不只是设施关门时间；○時までにここへ戻れば間に合いますか。 |
| 天气导致停运、延误 | 強風のため、運行を見合わせております。 | 暂停运行，不代表已有恢复时间；再開の見込みはありますか。 |
| 山顶路线、关闭区间 | この先は立入禁止です。／展望台はあちらです。 | 去哪里、哪些区域不能进入；ここから歩いて何分くらいですか。 |

**易混点**：`ロープウェイ` 与 `ケーブルカー` 是不同设施名称，旅行中中文都叫缆车时，先核对现场名称。`上り／下り`、`山頂／山麓`、`最終便` 要与方向一起听。天气影响运行是现实场景，例如 [箱根驹岳索道安全报告](https://ropeway.co.jp/wp-content/uploads/2025/02/2024%E5%AE%89%E5%85%A8%E5%A0%B1%E5%91%8A%E6%9B%B8-1.pdf)记有强风等导致停运；当日状态仍以现场为准。

## 六、电车与车站：从选车到出站

| 小场景 | 对方可能说什么 | 要听懂什么／我可以怎么说 |
|---|---|---|
| 线路、目的地与站台 | ○○方面は、○番線です。 | 方向与站台号；この電車は○○に行きますか。 |
| 普通、快速、急行的停站 | この電車は○○には停まりません。 | 不在目标站停车；○○に停まる電車はどれですか。 |
| 单程票、特急券与座位 | 別途、特急券が必要です。 | 可能还需另一个票种；この切符だけで乗れますか。 |
| 指定席、自由席、车厢 | 指定席は○号車です。 | 座位类别与车厢；この席に座ってもいいですか。 |
| 换乘与下一站 | ○○線はお乗り換えです。 | 哪条线在此换；ここで乗り換えればいいですか。 |
| 刷卡、余额、闸机与精算 | 残額が不足しています。／精算が必要です。 | 余额不足或需补差，不只是机器坏；どこで精算できますか。 |
| 晚点、停运与替代路线 | 運転を見合わせています。／到着が遅れています。 | 停止运行或晚到；○○へ行く別の方法はありますか。 |
| 下车、遗失物与求助 | お忘れ物のないよう、ご注意ください。 | 提醒带走物品；車内にかばんを忘れました。 |

**易混点**：`○番線` 是站台／股道号，`○号車` 是车厢号，`○番` 在其他服务场景可能是排队号码。指定席与自由席、特急券需求、错过班次的处理取决于列车及票种，不用一条规则套所有电车。[JR东日本票务目录](https://www.jreast.co.jp/kippu/)和[乗り越し精算说明](https://jreastfaq.jreast.co.jp/faq/show/1168?site_domain=default)可用于具体核对。

## 七、观光巴士：从集合到解散

这里优先练有预约、导游与行程安排的观光巴士；若实际是市内循环观光巴士，另外确认上下车、付款、再次乘车与末班规则。

| 小场景 | 对方可能说什么 | 要听懂什么／我可以怎么说 |
|---|---|---|
| 预约核对、上车地点 | ご予約のお名前をお願いします。／○番のりばです。 | 姓名与站点；○○です。／このツアーの集合場所はここですか。 |
| 上车、座位、安全带 | ご乗車ください。／シートベルトをお締めください。 | 开始登车／系安全带；席は決まっていますか。 |
| 行程与车窗讲解 | 右手に見えますのが○○です。 | 右侧可看到什么；左侧则听左手，不是人的手掌 |
| 下车游览与自由时间 | こちらで○分ほど自由時間となります。 | 可自由活动多久；何時までに戻ればいいですか。 |
| 集合与出发 | ○時にこちらへお戻りください。 | 回来时间与地点；集合もこの場所ですか。 |
| 道路、天气与变更 | 道路状況により、到着が遅れる場合がございます。 | 可能晚到／行程受条件影响；到着は何時ごろになりそうですか。 |
| 终点、解散与遗失物 | こちらで解散となります。／車内にお忘れ物はございませんか。 | 此处行程结束，拿齐物品；ありがとうございました。 |

**易混点**：`集合時刻` 与 `出発時刻` 不一定相同；`お戻りください` 是让乘客回来；`戻ってまいります` 可能是工作人员说明自己或车辆会回来。不能只听到戻る就断定是命令我。

运营方的具体流程例如 [はとバス乘车流程](https://www.hatobus.co.jp/guide/flow)区分集合、引导与发车环节；本页不把该公司的时间规定推广到其他巴士。

## 八、景点与观光设施：从入场到退场

| 小场景 | 对方可能说什么 | 要听懂什么／我可以怎么说 |
|---|---|---|
| 门票、年龄类别与套票 | 一般の方はこちらです。／共通券もございます。 | 普通票与联票；この券でどこまで入れますか。 |
| 预约时段、入场与再入场 | ご予約のお時間をご確認ください。／再入場はできません。 | 时段是否匹配／不能再次进；一度外に出ても戻れますか。 |
| 最后入场、闭馆 | 最終入場は○時です。／閉館は○時です。 | 最晚进入与必须结束参观；今からでも入れますか。 |
| 摄影、闪光灯、录像 | 撮影はご遠慮ください。／フラッシュは使用できません。 | 禁拍或只禁闪光，要听范围；写真は撮ってもいいですか。 |
| 鞋、行李、饮食与区域规则 | 靴をお脱ぎください。／お荷物をお預けください。 | 脱鞋／寄存，未必每处都需要；どこに置けばいいですか。 |
| 排队路线、封闭区域与导览 | 順路に沿ってお進みください。／本日は休止しております。 | 参观顺序／某项目暂停；この展示は今日は見られませんか。 |
| 纪念章、御朱印、纪念品窗口 | 受付は終了いたしました。 | 该窗口受理结束，不一定整个景点关门；明日は何時から受け付けていますか。 |

**易混点**：`ご遠慮ください` 在规则告示中通常表示请勿做，并非邀请我自行决定。`閉館`、`最終入場`、`受付終了`、`休止` 结束的对象不同。寺社等设施的规则按当地标示确认，不把拍照、脱鞋等要求概括为所有景点统一做法。

## 九、跨场景复用：这六类值得优先听出来

| 功能 | 高频词块 | 要问自己的问题 |
|---|---|---|
| 选择与确认 | いかがなさいますか／よろしいですか／ご希望ですか | 对方在问我选择，还是确认已有信息？ |
| 指示与请求 | お進みください／ご提示ください／お戻りください | 谁要做什么，在哪里做？ |
| 允许与可用 | ご利用いただけます／ご参加いただけます | 当前服务可用，是否还有条件？ |
| 否定与限制 | できません／いたしかねます／ご遠慮ください | 是不能做、无法办理，还是要求别做？ |
| 等待与不确定 | 少々お待ちください／見合わせ／見込み | 我在等什么，有没有确定恢复或完成时间？ |
| 结束与范围 | 以上／最後／終了／閉店／閉館／解散 | 是一项动作结束、一个阶段结束，还是整个服务结束？ |

这些功能要与名词一起记：`料理が終了`、`受付が終了`、`運行が終了` 对我的下一步含义完全不同。`ご利用` 可以泛指使用服务，但不能替代具体的点单、检票、填写、回程等步骤。

## 十、没听懂时，先确认范围与下一步

- `すみません、もう一度、ゆっくりお願いできますか。` 请慢一点重复。
- `○○ということですか。` 确认自己的理解。
- `私は、次に何をすればいいですか。` 明确下一步。
- `ここで待てばいいですか。` 确认等待地点。
- `何時までに戻ればいいですか。` 确认返回时间。
- `追加料金はかかりますか。` 确认额外费用。
- `これで全部ですか。` 确认是否全部完成；必要时把全部的对象说成コース、手続き等。

没听清时不只点头“はい”。如果已经听出大意，优先提出具体确认，比如“是套餐全上完了吗”，比请对方从头重复整串敬语更容易解决误解。

## 十一、用本次经历和朋友练

每次选一类，朋友随机挑三行，只给你听日文，不显示表格。你需说出“当前流程＋关键信息＋一句回应”。然后朋友把礼貌说法换成简单说法，你检查是否理解的是同一件事。

优先做三对：

1. 寿司：`握りは最後` 对比 `コースは以上`，确认还有没有后续。
2. 巴士：`○時に集合` 对比 `○時に出発`，确认自己要何时回来。
3. 景点：`最終入場` 对比 `閉館`，确认还能不能进、多久要离开。

每轮只记一个误听：原句／我当时以为的意思／真正范围／下一次的确认句。旅行回忆能提供练习素材；新增模拟句仍要标作模拟，不补写成“我当时一定听到了”。
