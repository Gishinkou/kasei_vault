# 敬语训练 ですます自动切换

目标：已有内容不用重新组织，也能用丁寧体自然说出来。

## 先改主句结尾

| 普通体 | 丁寧体 | 注意 |
|---|---|---|
| 行く／行った | 行きます／行きました | 五段动词变连用形 |
| 食べる／食べた | 食べます／食べました | 一段动词去る |
| する／した | します／しました | 不说するます |
| 来る／来た | 来ます／来ました | 读きます／きました |
| 分からない | 分かりません／分からないです | 两者可用，正式说明先练前者 |
| 面白い／面白かった | 面白いです／面白かったです | 不说面白いでした |
| 静かだ／静かだった | 静かです／静かでした | な形容词主句判断 |
| 学生だ／学生だった | 学生です／学生でした | 名词判断 |
| 行ってる | 行っています | 先恢复ている，再转换 |

形容词否定：`高くないです`，较正式可用 `高くありません`；过去 `高くなかったです`／`高くありませんでした`。名词／な形容词否定可用 `学生ではありません`，日常也会听到 `学生じゃないです`。

没把握时，先选一套最顺口且正确的形式：动词 -ません，い形容词 -くないです，名词／な形容词 -ではありません。熟练后再扩展，不需要为每句搜最隆重的版本。

## 从句通常保留普通形

**昨日行ったワールドは、とても面白かったです。**

`行った` 修饰ワールド，不能机械改成“昨日行きましたワールド”。句子整体礼貌由主句结尾承担，从句按自己的语法接续。

**明日は参加できると思います。**  
不是“参加できますと思います”。如果明确直接引用某人说的“参加できます”，可以保留引语内部的丁寧体；这和这里的判断句不是同一个结构。

**時間があれば、一緒に行きたいです。**  
条件 あれば 不要强改成ます型。**丁寧体不是每个动词都加ます。**

相关基础：[[13 一段动词与五段动词]]、[[15 动词与形容动词]]。

## 把三组结尾练成自动反应

1. 经历：`行きました／見ました／話しました`。
2. 判断：`面白いです／便利だと思います／よく分かりません`。
3. 计划：`参加します／行きたいです／まだ決めていません`。

每组先说三句短句，再说一句含从句的长句。五分钟计时，不盯着表逐词转换。

## 口头自测

对“今天刚认识、尚未约定用タメ口的人”说：

1. 昨日、友達と話した。
2. 昨日見たアバター、きれいだった。
3. 明日は行けると思う。
4. あのワールド、行ったことない。
5. 最近、日本語を勉強してる。

<details><summary>可用回答</summary>

1. 昨日、友達と話しました。
2. 昨日見たアバターは、きれいでした。
3. 明日は行けると思います。
4. あのワールドには、行ったことがありません。
5. 最近、日本語を勉強しています。

第2、3句内部保留普通形，主句结尾转为丁寧体；这些是刻意完整的训练句，实际会话中可适度省略。

</details>

验收：10 句随机转换至少 8 句正确，再不读稿聊两分钟，主句结尾大体稳定；自我修正可以接受。这个门槛只供训练使用。接 [[02 敬语训练 自然的礼貌会话]]。
