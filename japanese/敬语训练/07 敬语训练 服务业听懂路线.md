# 敬语训练 服务业听懂路线

目标：听出“对方现在要我回答什么／做什么”，然后按顾客身份回应。

## 先去掉包装，恢复业务动作

不要一边听一边给每个お／ご找中文译词。先抓对象：予約、名前、支払い、袋、本人確認；再抓动作：确认、选择、等待、出示、无法办理。

| 常见接待表达 | 核心意思 | 顾客可用的回复 |
|---|---|---|
| ご予約はございますか。 | 有预约吗 | はい、○○の名前で予約しています。 |
| ご注文はお決まりでしょうか。 | 点什么决定了吗 | はい、これを一つお願いします。 |
| 店内でお召し上がりですか。 | 在店内吃吗 | はい、店内でお願いします。 |
| お持ち帰りですか。 | 打包带走吗 | はい、持ち帰りでお願いします。 |
| お支払いはいかがなさいますか。 | 怎么付款 | カードでお願いします。 |
| 袋はご利用になりますか。 | 要袋子吗 | 袋は要りません。ありがとうございます。 |
| 少々お待ちいただけますか。 | 请等一会儿 | はい、大丈夫です。 |
| 身分証をご提示いただけますか。 | 请出示身份证明 | はい、こちらです。 |
| 本日は対応いたしかねます。 | 今天不能办理／处理 | いつでしたら対応できますか。 |
| こちらにご記入ください。 | 在这里填写 | ここに名前を書けばいいですか。 |

本表是用于角色扮演的常见形式，不是某店的逐字实录；实际说法会变化。点餐对话基础可查 [Erin 第8课](https://www.erin.jpf.go.jp/materials/key-phrases/download/erin_lesson08_key-phrases_explanation_zh.pdf)。

## ご利用这一类：词义相同，尾部决定功能

先将 `利用、購入、予約、記入、提示、確認` 还原为业务动作，再看请求、许可／可用性、感谢或否定。完整词表见 [[05 敬语训练 常用动词与接续#日常动作变成服务与业务概念|日常动作与业务词的对应]]。

| 同一核心词的表达             | 先抓的意思                   |
| -------------------- | ----------------------- |
| こちらのWi-Fiをご利用ください。   | 请使用这个Wi-Fi              |
| こちらのWi-Fiをご利用いただけます。 | 可以使用这个Wi-Fi，提供可用服务      |
| この設備をご利用いただけますか。     | 能否请你使用这个设备？问号与语境决定请求解释  |
| この設備をご利用いただけません。     | 不能使用这个设备                |
| ご利用いただき、ありがとうございます。  | 感谢你使用／惠顾                |
| ご利用方法はこちらです。         | 使用方法在这里；是在说明方法，不是发出使用请求 |

提供服务时的 `ご利用いただけます` 常可先整体理解为“您可以使用”；不要逐字卡在“店方能得到您使用”。但也不能把所有 `いただけます` 都当成对方请求你做事：陈述句与问句、对象、上下文都要一起判断。

同样，听到 `ご案内いたします` 是店方引导，听到 `ご記入ください` 是让顾客填写。**业务词帮助确定做什么，构文帮助确定谁做、能不能做、为什么说。**

## 五个值得整块识别的尾部

1. `ございます／でございます`：ある／です相关的郑重表达；`こちらが会場でございます` 就是“这边是会场”。
2. `なさいます／いらっしゃいます`：对方／顾客做，不能自动理解为店员做。
3. `いたします／しております`：店方郑重说明自己的行动或状态。
4. `〜ていただけますか／〜をお願いできますか`：常在请求顾客完成动作。
5. `〜かねます／〜かねる`：在 `対応いたしかねます` 等结构中表示难以／不能，不是“可以”。

`こちらでお待ちしております` 店方等你；`こちらでお待ちください` 请你在这里等。只差一些词尾，动作方向却不同。

## 听到长句时分段

**恐れ入りますが、ご本人様確認のため、こちらにお名前とご住所をご記入いただけますでしょうか。**

```text
恐れ入りますが / ご本人様確認のため /
こちらに / お名前とご住所を / ご記入いただけますでしょうか
前置礼貌 / 核实身份的目的 / 这里 / 姓名和地址 / 请你填写
```

顾客可以只答：`はい、分かりました。` 或具体确认 `住所もここに書けばいいですか。` 不用把对方整串敬语复述一遍。

`いただけますでしょうか` 等形式在实际接待中会听到；自己输出先用较简洁的 `いただけますか`。听懂实际表达与选定自己的默认说法，是两件事。

## 含糊拒绝、错误与听不清

`少々難しいかと存じます`、`あいにく…` 常提示困难／无法满足，但仍要听后面的条件和替代方案。不要只听见 `かと` 就认定“没有拒绝”。

你可以说：`すみません、今の説明は、今日は手続きができないということでしょうか。` 确认事项。若只没听清某处：`最後の、必要な書類のところをもう一度お願いできますか。`

金额、日期、座位与办理条件必须听准确。敬语包装听不全时，先请对方重复关键事实，不急着假装全懂。

## 听辨自测

让朋友随机念本页十句，不给你看文字。每句说“对象＋功能＋回复”。另外辨别 `お待ちしております` 和 `お待ちください`。
