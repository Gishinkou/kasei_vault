# 敬语从词典形到行动意图

目标：把 `なさいます、いただきます、ございます、最後になります` 还原到熟悉的词，再建立“我想完成什么 → 应该说什么”的输出习惯。听力反过来：先恢复对方的动作意图，再决定如何回答。

这是一套学习者的操作方法，不是断言日本人说话前都会在脑中逐步转换。熟练后应按场景调用整块表达，不需要临场逐词翻译。

## 一、先分清换词与活用

| 听到的形式   | 词典形与变化              | 熟悉的意义底座       |
| ------- | ------------------- | ------------- |
| なさいます   | なさる → 特殊ます接续 なさい＋ます | する 的尊敬表达      |
| いただきます  | いただく → いただき＋ます      | もらう；也可用于自己吃／喝 |
| ございます   | ござる → 特殊ます接续 ござい＋ます | ある 的郑重礼貌表达    |
| 最後になります | 最後＋に＋なる → なり＋ます     | 成为最后／在序列中到最后  |

`する → なさる` 是换成尊敬动词，不是把する按某个普通活用规则变出来；`なさる → なさいます` 才是该词的活用。`いただく` 是五段动词，く→き接ます；不是所有敬语都有特殊活用。

`ござる` 作为词形分析入口即可，日常不需要拿它的普通形聊天。现代会话优先整块记 `ございます、ございません、ございました`。

常用尊敬词及其ます形可核对 [国际交流基金教师用指导书](https://ba.jpf.go.jp/wp-content/uploads/2022/03/Teacher-Manual-Vol.6-2017-JP-2022.2.25.pdf)；类别与关系见 [文化庁敬语基本解说](https://www.bunka.go.jp/seisaku/kokugo_nihongo/kokugo_shisaku/keigo/chapter2/detail.html)。

## 二、なさいます：我在谈“对方做什么”

### 从熟悉的句子恢复

`どうしますか → どうなさいますか`：您打算怎么办？  
`何にしますか → 何になさいますか`：您选哪个？  
`利用しますか → ご利用なさいますか`：您要使用吗？

餐厅的 `お飲み物は何になさいますか`，先理解成“你选什么喝的”。`何にする` 是选择框架，不能逐词译为“把什么做成什么”。

### 行动指南

- 我是店员，要问顾客选择：可以调用 `何になさいますか`。
- 我是顾客，要选茶：说 `お茶をお願いします`，不说 `私はお茶になさいます`。
- 我问朋友选什么：`何にする？`；初次见面的轻松礼貌场景可用 `何にしますか`。

核心提醒：**なさる尊重行动者，不能用来抬高自己的动作。** 听到它时先找“是哪个人要作决定／做动作”，不要急着学对方句尾来答。

## 三、いただきます：先看前面接的是什么

### 1. 物をいただく：我接受东西

`先生から本をもらいました → 先生から本をいただきました`。

脑中先想“我接受对方给的东西”，说出来是在尊重相关给予者。不是“对方给我”也要把对方作主语接いただく；授受视角不同。

### 2. 食べる／飲む：我吃或喝

`お茶をいただきます` 可以表示“我喝茶／接受茶”，具体看场景。用餐前独立的 `いただきます` 又是固定表达，先整块记，不要求每次脑补一套隐含主语与宾语。

邀请顾客吃时用 `お召し上がりください` 等；不把自己的いただく直接移成 `いただいてください`。

### 3. 〜ていただく：我接受对方为我做的事

`説明してもらいました → 説明していただきました`。

```text
先生に説明していただきました
先生：实施说明的人
我：接受说明的人，常省略
整句：我接受了老师的说明
```

表面谓语是自己的“接受”，前面的“说明”却是老师做。不能只记“いただく＝自己做”，否则会把说明的行动者判断反。

### 4. いただけますか：借可能形式提出请求

```text
いただく → いただける（可能）→ いただけます → いただけますか
説明していただけますか：能否请您说明？
```

脑中想“我需要对方说明”，说出来是给对方回应请求的空间；不是“我能不能说明”。后者应说 `説明してもよろしいですか`。

### 行动指南

| 脑中实际需要 | 可用说法 | 谁做关键动作 |
|---|---|---|
| 我希望你重复 | もう一度言っていただけますか。 | 对方说 |
| 我感谢你解释 | 説明していただき、ありがとうございます。 | 对方解释，我受益 |
| 我想自己问问题 | 一つ質問してもいいですか。 | 我问 |
| 我感谢你给我时间 | お時間をいただき、ありがとうございます。 | 我获得对方的时间 |

注意服务提供中的 `こちらのWi-Fiをご利用いただけます`：通常是“您可以使用”，不是请求顾客一定使用。句末有无か、前项与场景一起决定功能；见 [[07 敬语训练 服务业听懂路线]]。

## 四、ございます：我在郑重说明“有／是”

先区分两个整块：

| 普通底座 | 郑重形式 | 功能 |
|---|---|---|
| あります | ございます | 存在、拥有、可提供 |
| ありません | ございません | 不存在、没有 |
| です | でございます | 判断、介绍身份／事物 |

`ご予約はございますか` → “有预约吗？”  
`お席がございます` → “有座位。”  
`こちらが出口でございます` → “这里是出口。”

不要把所有 `います` 都替换为ございます。说尊重的人在场通常用 `いらっしゃいます`；自己的存在按场景说 `います／おります`。

### 行动指南

- 店员郑重介绍或说明可提供的服务：可以用ございます／でございます。
- 我作为顾客答有预约：`はい、予約しています。○○です。`
- 我说自己的名字：日常 `○○です`，正式自我介绍 `○○と申します`。

不用因为对方说 `ございますか`，就强迫自己回一个ございます。它主要调整对听者的郑重程度，不表示“存在的东西被尊敬了”。

## 五、最後になります：这里的なる不是敬语专用动词

`なる → なります` 是规则的五段动词活用。“名词＋に＋なる”可表示成为某状态、结果或序列中的位置。

`次が最後になります`：接下来这一项将是最后。  
`これが最後の一品になります`：眼前这一道在课程序列中是最后一道；作为上菜说明理解。  
`握りはこれで最後です`：更直接说明握寿司部分到此结束。

某些服务表达将 `になります` 用于介绍当前事物，接近“是”。这类说法有用法和自然度上的讨论，不能从听到一次就推出“になります是です的万能高级版”；关于此用法的研究可参见 [ニナリマス敬語研究](https://surugadai.repo.nii.ac.jp/record/1009/files/Ronso31honda.pdf)。自己的简单介绍先用です。

### 不要与另一个なる构文混淆

- `最後になる`：最后＋に＋なる，状态／序列。
- `お帰りになる`：お＋动词连用形＋になる，是尊敬构文。

同样的なる出现在不同结构里。不能把 `最後になります` 自动解释成“尊敬最后”，也不能把 `お帰りになる` 只译为“变成回去”。

### 对照我的寿司经历

听到“最后”先确认范围：最后一贯？握寿司阶段？整个套餐？我作为顾客需要的是理解流程，不是复述主厨的敬语。

可说 `これでコースは全部ですか` 或 `この後、まだ何か出ますか`。完整回忆和范围对照在 [[14 日本旅行服务场景与听辨清单]]；这里的例句不作为当时原话的还原。

## 六、脑中只做三步，输出先调用稳定句块

### 第一步：先形成不带敬语的意思

例如“我需要你重复”“我想用卡付钱”“我想知道菜是否全上完”。先确定内容，不先寻找最隆重的词尾。

### 第二步：判断谁做、这句话做什么

我自己做／对方做／我接受帮助？是在说明、选择、请求、询问许可、确认流程还是感谢？

### 第三步：选一个适合自己身份的固定句块

| 脑中的意思 | 我要完成的行动 | 先练的输出 |
|---|---|---|
| 我选信用卡付款 | 告知选择 | カードでお願いします。 |
| 我没听清最后一句 | 请求重复 | 最後のところをもう一度お願いできますか。 |
| 我需要你确认 | 请求对方行动 | 確認していただけますか。 |
| 我想自己确认一件事 | 取得发问机会 | 一点、確認してもいいですか。 |
| 我接受并理解了说明 | 回应说明 | はい、分かりました。 |
| 我不能参加 | 清楚拒绝 | 今日は参加できません。 |
| 我不知道是否全结束 | 确认范围 | これで全部ですか。 |
| 我受到帮助 | 感谢 | ありがとうございます。助かりました。 |

练顺后再增加尊敬谦让词。先把**内容正确、行动方向正确、对方能回应**练稳；不是每次说前都完整分析三种敬语分类。

## 七、听到长敬语时的反向动作

```text
找实质对象：名字／票／付款／料理
→ 抓谓语和尾部：选择／请求／可用／否定／结束
→ 恢复对方意图
→ 按自己身份回应或确认
```

`お名前をご記入いただけますか`：对方请我写姓名 → 我填，或问在哪里填。  
`お支払いはいかがなさいますか`：对方问付款方式 → 我回答方式。  
`お料理は以上でございます`：对方宣布料理到此 → 我确认范围或致谢。

不要把每个敬语词都译出中文才允许自己回应。只认出少数关键词时，也不要装作全懂：用 `○○ということですか` 检查理解。

## 八、朋友给意图，你给一句话

朋友随机说中文或简单日语，只告诉你意图，不给敬语关键词：

1. 你是顾客，店员问付款，你要用卡。
2. 你没听清主厨是不是说整个套餐结束。
3. 你想请面试官再说一次问题。
4. 你作为工作人员想问顾客选哪种饮料。
5. 你想向面试官请求自己问一个问题。

1. `カードでお願いします。` 自己的选择，不用なさる。
2. `これでコースは全部ですか。` 明确结束范围。
3. `すみません、質問をもう一度言っていただけますか。` 面试官说，我接受帮助。
4. `お飲み物は何になさいますか。` 顾客选择，尊敬行动者。
5. `一点、質問してもよろしいでしょうか。` 我问，是许可框架，不是要求对方问。

随后换内容再练同一意图。能说出一句简单正确的话，比从记忆里拼出一条方向不明的长敬语句更能完成当下沟通。
