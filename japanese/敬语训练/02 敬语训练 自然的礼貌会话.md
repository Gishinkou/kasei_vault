# 敬语训练 自然的礼貌会话

目标：用です／ます聊天，仍能接住朋友的话，不变成朗读报告。

## 不只变动词，也调整回应与提问

| 朋友间常见   | 初次见面可练        | 场景说明               |
| ------- | ------------- | ------------------ |
| うん、分かった | はい、分かりました     | 接受说明；不必升级为かしこまりました |
| そうなんだ   | そうなんですね       | 接到新信息              |
| いいね     | いいですね         | 表达认同               |
| 何してる？   | 今、何をしているんですか？ | 询问情况，语气要柔和         |
| どこ住んでる？ | どちらにお住まいですか？  | 只在对方愿意谈居住地时问       |
| これ分かる？  | この表現、分かりますか？  | 指定对象，避免像考对方        |
| 俺は…     | 私は…           | 正式场景先练私，不是所有日常都禁用僕 |

`んですか` 在询问背景时很有用，也可能因语气和问题内容显得追问。敏感问题加“差し支えなければ”，或者不问，比单纯增加敬语更合适。不要把礼貌形式当作问任何私事的通行证。

## 用软连接保持会话感

- `最近、日本語を勉強しているんです。` 说明背景。
- `この言い方で合っているか、少し自信がないんですが…。` 为请求铺垫。
- `なるほど、そういうことなんですね。` 接住解释。
- `そうですね。私は少し違う見方をしています。` 给思考时间后表达差异。

句末 `んですが／んですけど` 可以给对方接话空间，不一定补出完整后半句。但重要请求仍要说清楚：`一度確認していただけますか`。不能指望所有人都猜到未说出口的需求。

## 减少容易让你自动滑回タメ口的触发词

先把 `うん、知らない、マジ？、何？、無理` 换成：`はい、よく分かりません、そうなんですか、もう一度お願いできますか、今日は難しいです`。不是宣布前一组词“永远无礼”，而是建立正式场景的替代反射。

与朋友练时可以保留笑声、兴趣、适度的ね／よ。`いいですね` 不需要平板念；反过来，尾音很冲的 `何ですか？` 也可能听起来不友好。让朋友分别评价“形式正确”和“听感自然”，不要只数ます。

## 把旧 VRChat 语料转成礼貌会话

来自 [[05 VRChat 对话场景控制]] 的意图，在新场景可说：

- 补一句：`少し補足してもいいですか。`
- 有同感：`それ、よく分かります。`
- 换话题：`少し話が変わるんですが…。`
- 请教看法：`○○さんなら、どうしますか。`

最后一句用名字＋さん，比每次用あなた自然得多。没有必要每次重复称呼，能省略就省略。

## 口头自测

刚认识的人说“最近、このゲームを始めたんです”。接话并问一个相关问题。随后说明自己没听清，需要重复。

<details><summary>可用回答</summary>

`そうなんですね。どんなところが面白いですか。`  
`すみません、最後のところが聞き取れませんでした。もう一度お願いできますか。`

不是只能用这些句子；关键是接话、相关提问和具体指出没听清的范围。

</details>

验收：五分钟礼貌闲聊，至少有两次自然接话、两次提问、一条没听清时的修复句。接 [[03 敬语训练 请求拒绝道歉与确认]]。
