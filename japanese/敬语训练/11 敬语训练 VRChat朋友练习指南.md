# 敬语训练 VRChat朋友练习指南

目标：在你熟悉的会话环境中建立礼貌模式，再把它带到其他场景。入口 [[00 日语敬语训练地图]]；记录用 [[12 敬语训练 六周计划与记录]]。

## 先告诉朋友这是短时间练习

下面是你可以自行发送或当面说的邀请，不要求对方当全天老师：

> 最近、日本での生活や面接に向けて、です・ますと敬語の練習をしています。よかったら、週に一、二回、十分くらいロールプレイに付き合ってもらえませんか。まずは語尾とお願いの言い方だけ、気になったところを教えてもらえると助かります。終わったら、いつもどおり話したいです。

录音时另问：`復習用に録音してもいいですか。共有はしません。` 只有得到同意才录；对方不愿意就会后记三条。不在公开房间收录无关人的声音。

如果朋友愿意帮忙但不熟悉正式敬语，也可以练自动切换、自然度与角色对话；存在争议的形式回查官方资料，不让一个人的直觉承担所有规则判断。

## 一次 20 分钟

| 时间   | 谁做什么                      |
| ---- | ------------------------- |
| 2 分钟 | 约定今天的角色、语体和唯一重点           |
| 5 分钟 | 第一轮自由对话；朋友先记录，除严重误解外不打断   |
| 3 分钟 | 朋友指出一条语体问题、一条不自然表达；你各重说一次 |
| 5 分钟 | 换一个内容，保持相同角色，检验能否迁移       |
| 3 分钟 | 交换角色，听朋友怎样表达；不要求完全模仿      |
| 2 分钟 | 写下一个保留句、一个待改句，然后回到普通聊天    |

只有 10 分钟时：1 分钟约定＋4 分钟对话＋2 分钟反馈＋2 分钟新追问＋1 分钟记录。没有朋友在线时，你可对提示卡作两分钟独白，但独白成绩不能代替互动成绩。

## 反馈方式：一次只抓一个标签

- **语体**：主句是否滑回普通体？修饰从句的普通形不算漏切换。
- **方向**：谁做动作，有没有用错尊敬／谦让？
- **功能**：是在请求别人做，还是问自己可不可以做？
- **听感**：是否太突然、太长、像命令？请朋友给一个替代表达。

每轮只选一个主标签，加一条听感反馈。回放十个句尾时，能自己修正也记录下来；不要把所有口误算成失败。

## 卡 A 初次见面：只练自然的です／ます

你：新加入小群的人。朋友：刚认识的成员。话题：喜欢的 world、来 VRChat 多久、今晚想做什么。

开头可说：`初めまして、○○です。よろしくお願いします。`

朋友可以问：`普段はどんなワールドに行っていますか。`  
你答：`最近は、友達と景色のきれいなワールドに行っています。○○さんは、どんなところが好きですか。`

**扰动**：朋友用普通体追问“へえ、なんで？”；你仍保持轻松礼貌。第二轮换话题，不背同一段回答。

验收：两分钟主句句尾大体稳定，至少接话一次、反问一次。从句如“景色のきれいな”不强加です。

## 卡 B 请教与拒绝：练请求功能

你：需要朋友解释一句日语，同时无法参加今晚活动。朋友：说明者兼邀请者。

你需要完成：询问一个表达、请对方再说一次、明确拒绝今晚、提出另一个时间。

可用片段：`この表現の意味を教えてもらえますか。`  
`すみません、最後のところをもう一度お願いできますか。`  
`今日は参加できませんが、明日なら参加できます。`

**扰动**：朋友说“じゃあ、明日の何時？”；你须给时间或说明还没确定，而不是只说大丈夫です。

验收：朋友不看提示也能复述你想知道什么、不能做什么、下一步是什么。

## 卡 C 餐厅／商店：你始终是顾客

朋友依次问：预约、人数、堂食／外带、点餐、付款方式。不要让朋友先给你日文答案。

可用脚本：

```text
店員：ご予約はございますか。
客：はい、○○の名前で予約しています。
店員：ご注文はお決まりでしょうか。
客：はい、こちらを一つお願いします。
店員：お飲み物はいかがなさいますか。
客：水をお願いします。
店員：お支払いはいかがなさいますか。
客：カードでお願いします。
```

**扰动**：朋友换成“本日はカードをご利用いただけません”。你先理解不能刷卡，再确认 `現金のみですか。`，不要继续回答カードでお願いします。

第二轮交换角色只为加深听懂，不把店员用语作为你平时聊天的默认输出。与 [[07 敬语训练 服务业听懂路线]] 联练。

## 卡 D 模拟面试：练事实与追问

你：候选人。朋友：面试官。问题卡只给朋友：

1. ご経歴を一分ほどで説明してください。
2. その仕事では、どの部分を担当されましたか。
3. 一番難しかったことは何ですか。
4. その改善は、どのように確認しましたか。
5. 何かご質問はございますか。

你先准备三个关键词，不写全文稿。技术经历用真实事实；朋友随机改问题顺序。不会答时可以澄清问题或承认经验范围，不能靠背诵绕开追问。

**扰动**：让朋友追问一个没有准备的问题。验收：五分钟里能清楚说明自己负责的范围，问一个逆質問，有一次自然澄清或思考请求。与 [[08 敬语训练 面试中的主动表达]] 联练。

## 卡 E 电话与日程：去掉视觉提示

双方坐在不同位置，不用手势；朋友可以发一张仅含日期、时间、地点的提示卡模拟邮件。用虚构但双方一致的信息，不放真实隐私。

你：求职者，来电确认或修改面试时间。朋友：担当者，先问名字，再给一个与你希望不同的时间。

你必须完成：报身份与事项、复述时间、说明冲突、提出可行时间、确认下一步。朋友最后复述结果；若结果不一致，继续澄清。

验收：日期／时间／地点无歧义。VRChat 模拟能练表达与压力管理，但不能代替真实电话音质、线下场景与礼仪的检验。

## 最后练模式切换，不练永久“装正式”

两分钟朋友普通聊天 → 五分钟初次见面 → 三分钟店员听辨 → 两分钟回到朋友聊天。每轮开头明确宣告角色。自然会话可能混用语体，训练先刻意分明，熟练后再理解真实的混用。

让朋友回答两个问题：`今の言い方は、意味は伝わりましたか。`／`この場面なら、どう言うと自然ですか。` 比只问“我的敬语对不对”更容易得到可用反馈。
