这组对应日语可以这样说，偏口语、适合聊天里用。

| 英语                                | 日语                                    | 中文感觉      |
| --------------------------------- | ------------------------------------- | --------- |
| **Classic.**                      | **あるあるだね。** / **典型的だね。**　ありがち（更加负面）   | 太典了 / 很典型 |
| **That checks out.**              | **まあ、そうなるよね。** / **それは納得。**           | 确实说得通     |
| **I feel that.**                  | **それ分かる。** / **めっちゃ分かる。**             | 我懂那种感觉    |
| **Just to add to that...**        | **それにちょっと付け加えると…** / **ちょっと補足すると…**   | 我补充一下     |
| **That reminds me of something.** | **それで思い出したんだけど…**                     | 说到这个我想起来  |
| **Here’s my take.**               | **自分の考えとしては…** / **個人的には…**           | 我的看法是     |
| **The weird part is...**          | **変なのは…** / **不思議なのは…**               | 奇怪的是      |
| **Okay, but what would you do?**  | **じゃあ、自分だったらどうする？** / **逆に、君ならどうする？** | 那你会怎么做    |

更自然的一组实战版：

**あるあるだね。**  
太典了。

**まあ、そうなるよね。**  
确实会变成那样。

**それめっちゃ分かる。**  
这个我太懂了。

**ちょっと補足すると…**  
我补充一下。

**それで思い出したんだけど…**  
说到这个我想起来。

**個人的には…**  
我个人觉得。

**変なのはさ…**  
奇怪的是啊……

**じゃあ、自分だったらどうする？**  
那如果是你，你会怎么做？
