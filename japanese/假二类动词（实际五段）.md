**以「る」结尾，而且「る」前面是 い段 / え段，看起来像二类动词，但实际上属于一类（五段）动词。**

|帰る|かえる|回去|

|知る|しる|知道|
|要る|いる|需要|
|減る|へる|减少|
|滑る|すべる|滑|
|喋る|しゃべる|说话、聊天|
|焦る|あせる|着急|
|限る|かぎる|限于|

|蹴る|ける|踢|

其中 N5～N3 最值得优先记的是这几个：

> **入る、走る、帰る、切る、知る、要る、減る、滑る、喋る、焦る、限る、握る、蹴る**

判断它们是不是一类，最直接的方法就是看变形：

- 帰る → 帰**ら**ない → 帰**り**ます
    
- 入る → 入**ら**ない → 入**り**ます
    
- 切る → 切**ら**ない → 切**り**ます
    
- 知る → 知**ら**ない → 知**り**ます
    

如果是二类，则应该是：

- 食べる → 食べない → 食べます
    
- 見る → 見ない → 見ます
    

所以你可以用一个非常实用的小技巧：

**看到「～いる / ～える」结尾时，如果不确定，试着想它的「ない形」。**

如果是：

> 帰**ら**ない  
> 知**ら**ない  
> 走**ら**ない

就是一类。

如果是：

> 見ない  
> 起きない  
> 食べない

就是二类。

另外有几组特别容易混，建议成对记：

| 一类         | 二类                |
| ---------- | ----------------- |
| 切る（きる，切）   | 着る（きる，穿）          |
| 要る（いる，需要）  | 居る（いる，在）          |
| 帰る（かえる，回去） | 変える（かえる，改变）       |
| 減る（へる，减少）  | 経る（へる，经过）※这个其实是二类 |
